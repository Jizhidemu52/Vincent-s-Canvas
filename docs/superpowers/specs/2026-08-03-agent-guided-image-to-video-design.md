# Agent 引导式图片转视频工作流设计

## 目标

让画布 Agent 在涉及动态画面时可靠地使用视频生成能力，并把图片、候选图和模型选择权交给用户。用户无需依靠更长的提示词来避免误路由。

## 用户流程

1. 用户在 Agent 中提出创作请求。
2. Agent 识别为以下两类之一：
   - 直接视频：走秀、动态、镜头、运镜、动作、动画、短片、视频等意图，创建视频阶段。
   - 图片转视频：明确提出先出图、选图后生成视频，先创建图片阶段。
3. Agent 对话消息内显示阶段卡片。图片阶段显示：参考图摘要、可用图片模型、生成数量和生成按钮。
4. 图片任务成功后，阶段卡片显示所有成功候选图缩略图。用户必须单选一张；没有选择时视频阶段禁用。
5. 用户选择候选图后，视频阶段显示：已选图片、可用视频模型、时长、比例和生成视频按钮。
6. 视频成功后，生成的视频节点写入画布并在阶段卡片中显示可跳转的结果状态。

## 模型职责

- Agent 模型：只负责理解请求、规划画布操作和提出默认值；不代表最终媒体生成模型。
- 图片模型：图片阶段的独立下拉框，只列出当前可用的图片能力模型。
- 视频模型：视频阶段的独立下拉框，只列出当前可用的视频能力模型。
- 两个媒体模型各自记住用户最近一次选择；Agent 模型继续使用独立设置，不与它们互相覆盖。

## 路由规则

- 对明确图片请求使用图片阶段。
- 对明确视频请求使用视频阶段。
- 对“先出图再生成视频”的复合请求使用图片转视频阶段。
- 当请求同时包含静态和动态描述但未说先出图时，默认建立直接视频阶段，并把当前选中的或引用的画布图片作为视频参考图。
- 视频关键词优先级高于服装、人物、场景等静态描述词，避免“走秀”因包含服装描述而误走图片生成。

## 错误与恢复

- 图片阶段失败时，显示该阶段的错误和重试按钮，视频阶段保持禁用。
- 没有成功候选图时不能进入视频阶段。
- 视频阶段失败时保留所选图片、模型和参数，可直接重试或更换模型。
- 上游 HTTPS 证书校验失败需明确显示为连接/证书问题，不伪装成生成失败，也不自动关闭证书校验。

## 数据与画布

- 工作流状态保存在 Agent 会话消息元数据中，并引用真实图片与视频节点 ID。
- 已选候选图在生成视频时作为唯一主图片参考；画布节点与来源关系持续可追溯。
- 现有手动图片、视频和画布节点生成方式继续可用，不改变其模型配置。

## 验收与测试

- “走秀视频”请求创建视频配置节点并调用视频生成，不调用图片生成。
- “先出图再做视频”请求先生成图片，未选择候选图时视频提交禁用。
- 选择一张候选图后，视频请求仅使用该图片作为主参考。
- 图片模型与视频模型下拉框只显示各自能力匹配的模型，并独立记忆选择。
- 图片失败、视频失败和证书错误均提供清晰、可恢复的提示。
