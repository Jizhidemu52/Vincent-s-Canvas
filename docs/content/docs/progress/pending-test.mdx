# 待测试

- 连续创作、原图上传、刷新恢复与安全提交的最新全量回归：前端 737 项、后端 243 项通过，前后端构建通过；9 项依赖数据库环境的本地后端用例跳过。覆盖任务提交前后中断、未知提交不重发、原消息恢复、保存失败重试和账号切换隔离。

- 生成中刷新已通过真实 Flare 编辑验证：上传绿圆原图，任务处理中刷新后只查询原任务，成功结果自动回填原消息；任务总数只增加 1，恢复期间没有再次提交。上传到服务端的参考图与原文件 SHA-256 相同；返回图实际核对为紫圆、蓝三角、白底和一次 `EAST 46`，不宣称非编辑区域逐像素一致。

- OpenToken 新增模型、协议配置和聊天附件修复已通过前端 616 项、后端 213 项测试、前后端类型检查及前端生产构建；9 项需数据库环境的后端用例跳过。后台 Provider 配置、画布 Agent 模型选择与只读工具往返已做页面验证，画布共用后台启用模型，不重复填写 Key。六个已启用对话模型均完成真实图片识别和 TXT／PDF／DOCX／XLSX 内容问答；GPT-6 Astra、Claude Fable 5.1 另完成浏览器五附件混合上传、多轮追问及刷新后问答，实际请求保留图片和四份文档文字。已修复 PDF worker、文件类型筛选残留、历史图片丢失及刷新后附件丢失；保存失败保留草稿、读取完成前禁止发送有针对性测试。旧版已经丢失的附件内容不能恢复，复杂扫描件、嵌入图片、超长文档及原生文件直传未覆盖。

- 两个 GPT Image 2.5 模型的生成和参考图编辑均取得真实成功结果，原图字节保持不变；Sunburst 曾有一次生成把同一行文字重复两处，严格内容验收未通过，不把接口成功视为构图完全合格。连续创作新增实测已完成 Flare 生图、Sunburst 自动引用上一版改色、刷新后识别最新版本，以及放入画布；圆形改色、蓝色三角形和一次 `EAST 46` 文字均实际核对正确，编辑输入与上一版原图 SHA-256 一致。纯讨论未新增图片任务。OpenToken 的 Responses 内建 `image_generation` 已真实调用验证为 HTTP 400 不支持；本次实现的是界面明确标识的“对话理解 + 图像任务”组合模式，不宣称原生图片工具可用。

- 模型 HTTPS 提交已改为原生 Node 验证连接，并修复整任务回退及非视频任务自动重试可能重复付费的问题。仅确认模型业务 HTTP 尚未发送的特定初始握手错误允许重试一次；显式代理失败不回退直连，响应、解析和下载失败不重放提交。测试仍观察到间歇性初始 TLS 断开，后续明确重试成功；尚不能定位到本机、网络出口或远端网关，未关闭证书校验。GPT 先前只读工具两轮约 129 秒和 128 秒，后续简单调用约 4 秒，不能承诺稳定低延迟。隔离模拟链路三轮、并发 2 的 12 项主用例及 3 项保护检查通过，不代表真实上游吞吐或长期稳定性。

- 画布图片交互与界面减负已通过前端 592 项测试、类型检查和生产构建。内置浏览器及 Edge 已验证：悬停只显示细框，选中显示四角控制点与三项常用工具，移开鼠标保留选中，点击空白处隐藏操作但保留参考图；已有内容的画布默认收起创建面板，收起入口约 124px 宽，顶部与底部无卡片边框和阴影，浅色与深色主题均可辨识；空画布桌面展开的规则有回归测试。“AI 编辑”可显式打开面板；390px 窄屏打开创建面板时暂时隐藏图片工具栏，关闭后恢复。原图内容与节点尺寸保留，截图自身带有的边框或控件属于图片内容，不会随取消选中消失。本轮没有新增付费调用；不同设备的触控手势仍未逐一实测。

- 图片交付与历史原图编辑已通过前端 581 项测试、类型检查、生产构建和隔离 Chrome 的完整操作验证：自定义 728×90 尺寸及透明边缘、撤销/重做、名称与 v1/v2/v3 版本传递、历史原图恢复后另存副本且原记录不变、素材副本重新插入画布、按指定顺序合并 PDF、逐图 PDF ZIP、保留原始图片字节的命名 ZIP，以及 100 张图片生成单个 100 页 PDF。下载 PDF 已渲染核对顺序和比例，缺失原图会阻止不完整下载，390px 移动视口和深色主题已核对。AI 编辑的版本传递使用模拟接口，不新增付费调用；大量高分辨率原图的设备内存承载未逐一实测，当前每次导出上限为 200 张、源文件合计 256MB，PDF 单图上限 2000 万像素，本地编辑上限 2500 万像素。

- 在线画布上下文与右键定位已完成前端自动化、隔离 Chrome 页面验证，以及 2 次经过本地应用 API 的 Gemini 3.1 Pro 真实识别：未选中标志中的红圆/蓝三角与 NORTH 27、视频中的红色花瓶/白色雏菊均识别正确，平移后识别 WEST 84 与绿色方形，不沿用旧图，并说明没有音轨。真实调用按合计 4 元保守预留，未超出用户授权的 10 元。右键定位的两批并发、滚轮缩放、非正方形结果不漂移、取消定位与节点原菜单用模拟 API 验证，不产生生图费。其他视觉模型、跨域限制媒体、超长视频和不同设备的触控仍未逐一实测；本地 Codex Agent 桥接不在本次自动多模态读取范围内。
