- 扩写输出严格校验会阻断缺字段及泄露，初轮出现五次缺 `keep_text`，未提交生图；追加输出契约后的双模型十例文字复测通过，不代表永不失败。一次上游提交断线仍为未知，未重新提交，需供应商侧核查；OpenToken 四模型余额不足未验收，不自动充值或替换渠道。正式 PostgreSQL/Redis 多进程中断恢复、真实双员工跨设备、长会话与批量高负载仍需目标环境覆盖。

- 画布共享配置的各模型输入组合、音视频真实分发及 100 张高分辨率批量改图仍需目标部署验证资源占用、限流与视觉质量；本机已验证双图逐图执行、合并参考和公共参考的真实图片任务，不代表所有模型及参数均已验收。共享配置目前覆盖画布四种生成模式，不包括所有专用工具；文本流不承诺刷新续传，图片与新音视频依赖已保存请求号查询，未知提交状态不得自动重发。小样改色仍可能改动纽扣颜色、构图或细微纹理，独立分发正确不等于严格保真。
