- 2026-10-20 追加的排队名次／耗时参考、提示词发送与插入画布、图片／视频工作台公共交互已完成本地针对性及隔离浏览器检查，本次仅更新代码和 GitHub。目标 PostgreSQL 仍需应用 `038_task_progress_indexes.sql` 及缺失前置迁移，并以真实员工、Redis 队列和画布同步验证；本地浏览器使用模拟任务和 API，未新增付费模型调用。名次仅指同模型当前可运行队列，预计时间不是完成保证；插入的是完整可编辑文字节点，参考图只保留可访问资产编号，不复制原件。

- 独立密码账号与可选积分已完成隔离 SQL／HTTP 检查，以及 CI 真实 PostgreSQL／Redis 的身份与多连接余额并发回归；目标 PostgreSQL、Redis、Worker 与对象存储部署仍待验收。隔离 CI 不代替目标环境的故障演练。页面隔离 QA 虽已接入普通项目／历史／团队／提示词／素材路由及本地文件适配器，仍禁止进程全局 `fetch`、不运行生成 Worker，也没有正式 S3；页面可操作不等于生产链路通过。

- 企业模式按“企业微信 → 公司 OA → 画布”完成真实员工身份联调，无额外扫码；核验失效/错误 token 不回退访客、不沿用另一员工身份。当前本机免登录试用不是企业正式入口。

- 正式 PostgreSQL 环境需按顺序执行全部迁移，包括 OA、`023_canvas_documents.sql`、`024_model_public_numbers.sql`、`025_design_library.sql`、`026_formal_module_configuration.sql`、`027_midjourney_blend_module.sql`、`028_usage_analytics.sql`、`029_model_presentation_settings.sql`、`030_credit_policy.sql` 和 `039_creative_design_tools.sql`。核验公开模型展示、请求配置 UUID、当前 AI 绑定和模块目录、原配置保留与数据库权限；新增创意场景的模型绑定、费用覆盖、父级／子级开关以及两个本地矢量工具不产生 AI 费用，均须在目标环境检查。早期九模型配置的隔离 SQL 加密／重开库验证，以及当前目录和界面检查，都不代替目标数据库迁移验收。
- 公司服务器现已完成构建、启动与更新前备份，API、Worker、PostgreSQL、Redis、MinIO 健康和业务数据保全检查通过。仍需逐板块验证设计师实际操作、队列、历史和对象存储链路，不能把服务健康或静态资源可达当作全部交付验收。

## 画布与数据恢复

- 真实员工 A 保存文字与原图，确认已同步后刷新、关闭重开、重启服务和换设备仍可从 OA 恢复；员工 B 不能列表、读取或下载 A 的画布和媒体。双设备改动冲突及删除墓碑防复活需在目标环境验收。
- 正式 PostgreSQL 与 S3/MinIO 的原图字节、对象访问权限、跨设备下载、素材元数据/审计联动，以及数据库和文件联合备份恢复。
- 目标电脑存储容量不足、浏览器策略、断网重连、触控笔/触控板、超大画布和高分辨率图片组合；不同浏览器／系统策略下的节点复制、剪切、粘贴、快速副本及文本输入焦点隔离仍需目标电脑验证。已有单元与隔离浏览器测试覆盖本地合并、云同步、失败重试、原文件 ZIP 和账号隔离。
- 独立聊天、创意工作台和“我的模板”仍为员工分区的浏览器数据，试用画布也仅本地保存；个人模板暂不跨设备同步。创意场景及图案分层已保存原请求号／任务号，可在最近任务或待恢复图层中查询原任务，不自动重新生成；目标环境仍需验证断网、强制关闭与身份切换时的恢复。不要清理网站数据或把本地自动保存当作已云同步。旧共用/其他员工内容不自动迁移或公开。
