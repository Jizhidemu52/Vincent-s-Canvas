# 待测试

- 生产式验证已在隔离的 GitHub CI 环境完成：前端、服务端、PostgreSQL/Redis 权限隔离，以及 Docker 全栈数据库备份/对象存储恢复均通过。新增 6 项真实数据库并发用例，覆盖同部门、同用户、有限预算、重复请求及小组结算；连同原权限用例共 7 项集成测试通过。自动验证记录见 [Production backend verification](https://github.com/Jizhidemu52/Vincent-s-Canvas/actions/workflows/production-ci.yml)。此结果不表示已经部署到公司生产服务器，也不代替供应商逐模型实付验收。
- 同一运行的 40 人模拟提交压测共 4722 次请求，失败率 0%，请求耗时 p95 为 36.84 ms。该阶段验证任务提交与结算链路，使用模拟 Provider，不等同于真实 AI 服务的出图或出片速度。
- 本轮补齐全板块操作说明、安装说明和图像/视频/聊天参数说明；新增按模型显示参数、原文件名下载、跨标签页按画布合并保存及失败写入保留改动。仍需在目标浏览器验证同一画布多窗口编辑的业务习惯，以及实际存储容量不足时的备份处理；同一画布同时编辑仍按最后写入为准。

- Agent 图生视频引导流程：仅显式 `image_to_video` 或“先出图再视频”的请求需要用户从成功候选图中手动选择恰好一张后才能提交视频；图片模型和视频模型彼此独立，且只展示各自能力匹配的模型；“走秀”“动态”“视频”等 direct-video 请求不创建图片任务，进入视频模块后可直接提交。
- 本地浏览器此前已完成创建图片、参考图编辑、Agent 分析后生图、直接图生视频及视频播放的真实 Provider 验证；画布点选/框选图片自动进入左侧编辑区、参考图点击/拖动排序和按顺序提交双图编辑也已验证。上游证书错误时的恢复重试和候选图保留、真实企业微信配置，以及所有账号可用模型的付费验收仍需单独确认。
- 已修复额度冻结时任务外键锁与余额锁冲突造成的并发死锁，仍保留任务创建与冻结的同事务去重；另修复画布预览忽略已恢复本地媒体、继续请求过期服务器链接的问题。本地媒体缺失时才回退到原链接。
