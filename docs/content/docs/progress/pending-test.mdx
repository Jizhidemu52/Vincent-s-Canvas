# 待测试

- 在线画布上下文与右键定位已完成前端自动化、隔离 Chrome 页面验证，以及 2 次经过本地应用 API 的 Gemini 3.1 Pro 真实识别：未选中标志中的红圆/蓝三角与 NORTH 27、视频中的红色花瓶/白色雏菊均识别正确，平移后识别 WEST 84 与绿色方形，不沿用旧图，并说明没有音轨。真实调用按合计 4 元保守预留，未超出用户授权的 10 元。右键定位的两批并发、滚轮缩放、非正方形结果不漂移、取消定位与节点原菜单用模拟 API 验证，不产生生图费。其他视觉模型、跨域限制媒体、超长视频和不同设备的触控仍未逐一实测；本地 Codex Agent 桥接不在本次自动多模态读取范围内。

- 单张透明图编辑已完成 5 次合格的 OpenToken 真实返回验证：使用原始透明针织衫，明确只改紫色领边，五份 PNG 均保持衣身奶油白及真实透明背景；最后两次通过完整画布入口提交。另有一次改色范围不符、一次超时，均不计成功。输入上传字节及输出保存字节一致性通过隔离浏览器验证，不新增开关或图像后处理。前端 548 项、后端 196 项测试通过（9 项数据库环境测试跳过），前后端构建通过；其他模型、多图和蒙版透明输出仍不在本次验证范围内。

- 本轮手动图片编辑已通过独立 Chrome 的真实像素验证：涂画、裁剪、矩形拖动、撤销/重做、原节点保存、刷新重开、取消不修改、存储失败后重试以及 390px 移动视口；此前前端 544 项测试通过，矩形拖动与自适应新增验证为 7 项针对性测试及最新前端构建通过。浏览器使用实际构建产物与隔离的模拟 API，未调用付费模型。当前 3001 本地服务已运行，用户需保存草稿后刷新载入新构建；不同设备的触控笔、超大图片以及企业实际浏览器策略未验证。
- 图片编辑漏图修复：已复现选择图片后点击画布空白处会清空参考图、编辑入口退回文生图的问题；现在取消选中保留编辑参考图，显式移除/清空仍有效。17 项针对性测试及最新构建通过；隔离 Chrome 实测手动编辑保存、点击空白处、按钮与 Ctrl+Enter 提交均上传原图并发送 `inpaint`、非空 `sourceUrls` 和 `size=auto`。用户历史“领口改紫色”任务确实没有参考图，但无法回溯确认其具体点击顺序；本次覆盖已复现的漏图路径。专项测试在请求进入收费模型前截断，未验证新的真实模型编辑结果。
- 素材编辑与提示词保存已模拟验证失败保留输入、连续点击只提交一次、素材编辑后重新进入仍保留、125 条模板跨页访问及参数保留。新增素材元数据接口已通过字段白名单测试，真实 PostgreSQL 环境下的权限/审计与对象存储联动仍待部署环境验证；演示服务仍使用内存素材，不承诺进程重启后持久保存。
- 画布键盘防误触、失焦复位和无变化保存去重已补回归测试；独立浏览器已验证键盘事件。本地服务已运行，完整画布的拖拽后切换窗口、输入法操作与撤销重做组合仍需在目标人工使用环境验证。
- 生产式验证已在隔离的 GitHub CI 环境完成：前端、服务端、PostgreSQL/Redis 权限隔离，以及 Docker 全栈数据库备份/对象存储恢复均通过。新增 6 项真实数据库并发用例，覆盖同部门、同用户、有限预算、重复请求及小组结算；连同原权限用例共 7 项集成测试通过。自动验证记录见 [Production backend verification](https://github.com/Jizhidemu52/Vincent-s-Canvas/actions/workflows/production-ci.yml)。此结果不表示已经部署到公司生产服务器，也不代替供应商逐模型实付验收。
- 同一运行的 40 人模拟提交压测共 4722 次请求，失败率 0%，请求耗时 p95 为 36.84 ms。该阶段验证任务提交与结算链路，使用模拟 Provider，不等同于真实 AI 服务的出图或出片速度。
- 本轮补齐全板块操作说明、安装说明和图像/视频/聊天参数说明；新增按模型显示参数、原文件名下载、跨标签页按画布合并保存及失败写入保留改动。仍需在目标浏览器验证同一画布多窗口编辑的业务习惯，以及实际存储容量不足时的备份处理；同一画布同时编辑仍按最后写入为准。

- Agent 图生视频引导流程：仅显式 `image_to_video` 或“先出图再视频”的请求需要用户从成功候选图中手动选择恰好一张后才能提交视频；图片模型和视频模型彼此独立，且只展示各自能力匹配的模型；“走秀”“动态”“视频”等 direct-video 请求不创建图片任务，进入视频模块后可直接提交。
- 本地浏览器此前已完成创建图片、参考图编辑、Agent 分析后生图、直接图生视频及视频播放的真实 Provider 验证；画布点选/框选图片自动进入左侧编辑区、参考图点击/拖动排序和按顺序提交双图编辑也已验证。上游证书错误时的恢复重试和候选图保留、真实企业微信配置，以及所有账号可用模型的付费验收仍需单独确认。
- 已修复额度冻结时任务外键锁与余额锁冲突造成的并发死锁，仍保留任务创建与冻结的同事务去重；另修复画布预览忽略已恢复本地媒体、继续请求过期服务器链接的问题。本地媒体缺失时才回退到原链接。

- 高级视频媒体链路已接通，服务端从真实媒体字节读取元数据；图片、视频和音频引用顺序、编辑模式自动时长、所有权、公开 HTTPS、格式、大小、时长、尺寸和帧率均有自动验证。创作台已浏览器验证编辑模式锁定比例/时长，切换到不支持媒体的模型会保留素材并禁止生成。
