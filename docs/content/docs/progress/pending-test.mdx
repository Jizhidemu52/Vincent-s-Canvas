# 待验收

这里只保留尚未完成的真实环境验收。已实现能力见 [功能介绍](/docs/overview/features)，历史变更见仓库 `CHANGELOG.md`；旧测试次数和临时服务地址不作为当前状态。

## 公司部署与访问范围

- 独立密码账号与可选积分已完成本地隔离 SQL／HTTP 检查；目标 PostgreSQL、Redis、Worker 与对象存储部署仍待验收。真实 PostgreSQL 多连接余额并发用例已提供但本机未运行，不以单连接 PGlite 代称锁并发通过。隔离 QA 虽已接入普通项目／历史／团队／提示词／素材路由及本地文件适配器，仍禁止进程全局 `fetch`、不运行生成 Worker，也没有正式 S3；页面可操作不等于生产链路通过。
- 文字请求进程异常退出后残留的冻结尚无自动恢复，正式启用收费前需补目标环境故障演练及处理方案。正常错误和连接中断退款已覆盖本地测试，但断连在后续上游事件、完成或既有超时处处理，不承诺立即中断上游；此行为不能替代进程被强制终止的验收。

- 企业模式按“企业微信 → 公司 OA → 画布”完成真实员工身份联调，无额外扫码；核验失效/错误 token 不回退访客、不沿用另一员工身份。当前本机免登录试用不是企业正式入口。
- 公司服务器位置、正式 HTTPS 域名、公司出口 IP/网段和可信 OA 接口由 IT 确认；网关/防火墙须同时限制网页、API、媒体与后端端口，并从公司外网络实测拒绝访问。此网络限制尚未落实，不能仅看 OA 登录来源或信任客户端转发头。
- 核验生产管理员独立密码入口及角色保护；管理员不能借维护身份自动进入员工画布，日志不得记录真实员工 token。单机演示不提供管理员登录入口。
- 正式 PostgreSQL 环境需按顺序执行全部迁移，包括 OA、`023_canvas_documents.sql`、`024_model_public_numbers.sql`、`025_design_library.sql`、`026_formal_module_configuration.sql`、`027_midjourney_blend_module.sql`、`028_usage_analytics.sql`、`029_model_presentation_settings.sql` 和 `030_credit_policy.sql`。核验公开模型展示、请求配置 UUID、27 个 AI 绑定和 44 项模块目录、原配置保留与数据库权限。早期九模型配置的隔离 SQL 加密／重开库验证，以及当前目录和界面检查，都不代替目标数据库迁移验收。
- Docker 静态资源路径和目标环境构建/启动仍需核验。隔离 CI 的 PostgreSQL、Redis、Compose 恢复与模拟并发通过，不等于公司服务器已部署。

## 画布与数据恢复

- 真实员工 A 保存文字与原图，确认已同步后刷新、关闭重开、重启服务和换设备仍可从 OA 恢复；员工 B 不能列表、读取或下载 A 的画布和媒体。双设备改动冲突及删除墓碑防复活需在目标环境验收。
- 正式 PostgreSQL 与 S3/MinIO 的原图字节、对象访问权限、跨设备下载、素材元数据/审计联动，以及数据库和文件联合备份恢复。
- 目标电脑存储容量不足、浏览器策略、断网重连、触控笔/触控板、超大画布和高分辨率图片组合。已有单元与隔离浏览器测试覆盖本地合并、云同步、失败重试、原文件 ZIP 和账号隔离。
- 独立聊天、创意工作台和“我的模板”仍为员工分区的浏览器数据，试用画布也仅本地保存；个人模板暂不跨设备同步，创意场景生成中刷新暂不恢复运行结果。不要清理网站数据或把本地自动保存当作已云同步。旧共用/其他员工内容不自动迁移或公开。

## 公司设计灵感库

- 在真实 OA 入口用两个员工验证显式发布、公司列表、原图下载、提示词复制、加入各自私有画布及跨设备恢复；未发布的源素材和私人画布不能被同事读取，切换员工后不能继续提交前一身份的操作。当前试用部署仍关闭该功能，本地测试身份不能替代真实员工验收。
- 在目标 PostgreSQL／S3 或 MinIO 环境验证 `025_design_library.sql`、独立快照与复用原件的字节／权限、失败回滚、幂等重试、作者操作排除、逐图及跨图人数去重、下载／复用收据和联合备份恢复。下载收据不作为外部真实使用的证明。
- 在正式独立管理员入口验证部门范围、下架原因审计、作者撤回后新共享操作被拒绝，以及已签发收据可完成、已有下载和私有副本保留；单机演示不提供真实管理员验收条件。

## 常用导航与人员使用分析

- 在真实 OA 入口用两名员工和独立超级管理员验证访问归属、切换账号、常用板块排序、实际操作及生成／聊天记录关联；普通用户与部门管理员不可读取人员统计。单机试用不提供人员分析，不能用共用身份替代员工验收。
- 在目标 PostgreSQL 和浏览器策略下验证迁移 `028_usage_analytics.sql`、大批量导出、桌面保存权限、断线后事件重传与缺口提示。已采集数据可完整导出，不代表启用前的点击、未上报操作或历史聊天可以恢复。
- 深入分析的模型调用以用户预览并确认的内容为准；本轮用假模型检查冻结输入、单次调用和失败不重试，没有新增真实付费分析。投入使用前按公司制度确认员工告知、留存和向所选模型发送脱敏摘要的授权。

## 生成与设计质量

- APIMart 当前目录为十模型；早期九模型、复杂毛衫各独立出图板块及文字／视频的本机真实测试范围见参数手册，不据此宣称当前十模型及全部参数均已付费验收。仍需目标 PostgreSQL／Worker／存储环境验证迁移、并发和恢复，以及更多业务素材的生成质量；同名 OpenToken 的结果不能代替此通道验收。部分概念图存在颜色、视角、钮扣数量、花型提取或局部范围偏差，不宣称视觉全部合格。

- 三个正式设计工作台仍需用生产素材验证：图案定位的高分辨率合成与打印尺寸、花型循环的实际接缝与印花效果、系列配方的结构／材料／配色遵循。系列配方已完成两种复杂毛衫场景真实生成，本地定位／循环也完成不同操作验证；不等于生产文件或所有视觉要求合格。工程与草稿仍为浏览器身份分区，换设备前先导出。
- 对话改图仍需扩充业务样本：上传要求文件后改图、新图与颜色参考的语义判断、长对话保留条件、多图对象切换及复杂局部修改。独立对话与画布对话均已完成两轮实际改色／改纽扣，并核对第二轮沿用第一轮结果；小样出现细微纹理、明暗与纽扣细节重绘，不能宣称其余区域完全不变。基础连续调用通过不等于上述复杂样本或严格局部编辑合格；本模块仍是应用编排，不是 ChatGPT 私有对话接口。
- 内置网页采集的公司服务器出口 DNS／TLS、目标公开网站防爬和 CDN 可用性需在目标环境验收；不执行 JavaScript、不携带网站登录态，也不使用模型代理设置，因此只允许代理出网的环境可能无法直连。可选扩展在公司 Chrome 策略、原生可选站点授权弹窗和工具栏点击授权下需人工验收，须由用户或 IT 安装。隔离浏览器测试覆盖内置审核、确认入库及返回画布；扩展的传输测试使用临时 localhost 预授权，不代表原生授权交互已自动验收，单个站点的访问限制不能绕过。
- 服装画布模板的技术线稿、工艺表现和系列配色需实际样本验收；流程创建与历史输入恢复不等于生成质量或生产文件合格，也不保证随机生成结果逐像素一致。
- 创意设计九个场景的复杂面料、花型细节、色号、辅料结构和生产适用性，需用实际业务样本验收。现有线稿、局部改款与精确换色小样不代表所有场景合格。
- 服装指定颜色的标准色库已完成单张 Sunburst 真实收费链路验收：浅蓝衬衫样图按 PANTONE TCX 18-1664 的屏幕参考 HEX 换红色，概念配色、蓝色纽扣和主要结构保留可用。深浅面料、强光阴影、多部位配色与真实业务照片仍需样本验收；生成会改变局部纹理和明暗，不承诺逐像素保真或实物标准色差。
- SVG 在目标浏览器的实际下载，以及复杂图片的路径质量、选区合成接缝和不同返回比例。结构与选区外像素的自动检查已通过。
- 逐个账号与供应商验证实际可用模型、限流、超时、费用和图像质量；接口成功不代表文字、构图、透明度或局部编辑完全符合要求。
- 当前 OpenToken 四模型已完成基础改色真实小样，Flare 2K 与 Sunburst 4K 返回尺寸正确；但指定 WebP/JPEG 的两次渠道原件均为 PNG，Flare 独立矩形蒙版原件出现范围外改色。新增服务端无损蒙版合成与真实格式/质量编码不改变上述渠道结论；渠道原生蒙版遵循、格式/压缩执行、透明背景及更多质量组合仍需确认与业务样本验证。新后处理链路仍需部署到目标服务器后验收 FFmpeg/ffprobe 可用性、权限、真实素材及并发资源占用，不以离线检查替代生产验收。
- 剩余视频实付范围包括 MiniMax 多视频/音频参考、Seedance 编辑/延长/音频参考、Wan 续写/自定义音频及其他未覆盖的帧/参考组合。远程音视频引用需供应商可访问的 HTTPS 地址，真人素材受渠道审核。
- 正式服务器已复现间歇性初始 TLS 失败，切换备用官方网关未改善，已恢复原网关。代码已增加每次 10 秒的提交前建连上限、最多一次安全重连及失败审计中的分次连接耗时，仍需部署 Worker 后实测；服务器出口／代理与上游网关的具体断连位置尚未确定。保持证书校验，10 秒限制不截断已开始的模型生成；业务提交结果未知时先查询原任务，不能整单自动重发。WSL 冷启动测试服务也有准备耗时，此前 APIMart 两次失败的上游执行与计费状态未确认。

新增付费测试应单独明确范围与预算；本页不构成自动调用模型的授权。
