# 快速开始

本页适用于完整 Docker 部署。根目录模板与 Compose 默认关闭 OA 员工识别（`OA_LOGIN_ENABLED=false`），打开即可试用；Compose 的 API 与 Worker 设置会覆盖旧 `.env` 中的开启值。此模式不代表员工隔离或公司正式入口，只能放在受信网络或受控入口后。Windows 试用见 [部署导航](https://github.com/Jizhidemu52/Vincent-s-Canvas/blob/main/docs/manual/installation-guide.md)；真实模型调用仍可能收费。

## 1. 准备环境

安装 Docker Engine 与 Docker Compose，克隆仓库后进入项目目录：

```bash
git clone https://github.com/Jizhidemu52/Vincent-s-Canvas.git
cd Vincent-s-Canvas
cp .env.example .env
```

编辑 `.env`，至少替换数据库密码、首位管理员初始密码、Provider 加密密钥和对象存储密钥。若需要企业 OA 员工身份与云同步，先按 [公司 OA 接入](https://github.com/Jizhidemu52/Vincent-s-Canvas/blob/main/docs/manual/oa-workspace-integration.md) 由 IT 确认可信身份接口、HTTPS 和网络限制，再显式调整 API 与 Worker 的 Compose 覆盖配置；只修改 `.env` 不会启用 OA。

## 2. 启动完整服务

```bash
docker compose up -d --build
docker compose ps
curl http://localhost:3000/api/health
```

## 3. 首次管理员登录

1. 维护人员通过已配置的 HTTPS 地址打开 `/admin/login`（生产 Cookie 需要 HTTPS）。
2. 使用 `.env` 中的超级管理员账号和初始密码。
3. 按提示修改密码。
4. 进入模型配置；无需为普通创作用户开通账号。

## 4. 从公司 OA 进入创作

本节仅适用于已显式启用并联调企业 OA 的部署。默认免登录试用直接打开画布地址，不具备以下员工身份与云同步保证。

1. 企业微信打开公司 OA，再点画布菜单，入口自动携带可验证的临时身份凭证。
2. 画布验证 OA 身份后加载本人数据，不新增扫码、密码或内部积分；凭证失效时返回 OA，不回退访客。
3. 企业画布与原图先保存员工本地缓存，再同步服务器；确认已同步后，关闭重开或换设备可由本人从 OA 恢复。
4. 独立聊天、创意草稿和试用画布仍在浏览器，换环境前另存/导出；分享链接不授予他人访问权限。

## 5. 配置模型

维护人员在受保护的后台配置 Provider、工作流和模型。API Key 加密保存在服务端，创作端只看到公开模型信息，不展示内部积分限制。

需要先验证业务链路时，在测试环境设置 `TASK_MOCK_MODE=true`；确认任务、素材和历史后必须在真实生成环境改回 `false`。

详细步骤和截图见 [操作手册](https://github.com/Jizhidemu52/Vincent-s-Canvas/blob/main/docs/manual/user-guide.md) 与 [生产部署手册](https://github.com/Jizhidemu52/Vincent-s-Canvas/blob/main/docs/manual/production-deployment.md)。
