# 功能介绍

本页描述当前实现；统一工作台界面、非阻塞任务与财务展示清理尚待本轮发布。已完成实现不等于目标环境已部署或全部模型验收通过，具体边界见[待验收](/docs/progress/pending-test)。

## 统一工作台与独立任务

- 自由画布始终是有权限时的首个导航入口，对话与工作台随后排列，访问其他页面不会改变顺序；分组可折叠，最近使用放在首页，提示词库用共享／个人页签。使用记录说明与原有帮助入口保留在底部帮助菜单中。中性色、六档字号、圆角、控件、悬停提示、按下反馈与加载占位统一，遵守系统减少动态效果设置；复制成功在操作旁显示短暂回执。
- 图片、视频、无缝拼接使用参数与结果两栏，主要操作固定在参数栏底部；历史记录放在结果页签中，图片以原比例主图与缩略图条展示，未完成与失败结果仍可选中查看。生成期间仍可新建独立任务、切换任务和浏览历史；每个结果写回所属任务，查看旧记录不会覆盖当前运行结果。
- 对话中的请求按会话独立处理；切换会话保留当前页面内尚未提交的文字、附件、参考关系、选区和编辑状态。成功保存只清理原提交版本，失败保留输入；未提交草稿不承诺刷新后恢复。已提交消息与原任务继续沿用已有持久化和恢复机制。
- 自由画布的顶栏管理当前文件，底部工具栏负责添加与视图；图片更多菜单和右键菜单共用分组。新导入内容避让已有节点，打开画布时显示全部，可缩放到选中；直接下载原文件，另存格式另行选择。面板收起动画不取消已授权任务，隐藏状态不能继续误操作。
- 使用者、管理后台、小组与分析页面不展示积分、费用、价格入口；使用明细与任务报表导出也移除对应字段。用于恢复的完整配置备份不裁剪原配置。后台原账务、费率与提交校验保留；隐藏展示不表示模型免费，也不更改历史数据。设计效能的今日使用人数按北京时间和账号去重，不随日期筛选变化，人员与权限筛选仍生效。

## 导航与历史保留

图像生成／编辑、托管图片工具、视频、创意场景、无缝拼接与图层工作区提供账号云端历史：从原板块按页读取本账号已提交任务的完整提示词、参数、状态及已保存原件，换浏览器仍可查看。打开历史不提交生成，不覆盖当前草稿，不把云端记录加入本机批量删除。记录只按明确保存的板块来源归类；未提交草稿、本机合成或图层位置不会凭空同步，缺少来源或原件的旧记录也不伪造恢复。当前浏览器原有历史继续保留。

局部改款、服装配色、背面设计移至主导航创作组最前方，提供独立入口；旧创意链接保留参数并跳转，沿用原员工草稿与素材身份，不复制或清空历史。细节增强、角度控制和系列配方的用户入口退役，旧链接提示已下线；原任务、素材、历史与内部配置保留，高清放大及其内部工具映射不受影响。下文保留的历史能力说明不表示退休入口仍能创建新任务。

## 图层拆分与图片生成

独立工作区提供文字生成、0–10张参考图编辑／融合、透明PNG，以及单图拆分与可选OCR。拆分可设置2–100张输出上限（包含底图），不保证模型一定返回指定数量；提示词优化使用上游 standard，不能关闭。生成支持档位、十种比例与精确像素，拆分仅支持 auto／1K／1.5K／2K；前台不展示真实模型名称。

结果原件逐张保存到员工私有素材，编辑器支持选择、移动、等比或数值缩放、显隐、排序、复位、单层原件下载及PNG合成。摆放使用模型实际bbox，而非图层文件分辨率；没有位置或OCR时明确提示，不补造识别结果。编辑变换与历史索引是当前浏览器的员工分区数据，不能据此承诺跨设备同步。

请求身份先持久保存再提交，刷新或断连只查询原请求；部分原件保存失败可继续原任务，不重新生成。后台按原配置进行提交校验，界面不展示预计费用。HTTP 环境的上传与原件摘要校验不依赖浏览器 `crypto.subtle`。上述实现与隔离检查不等同真实供应商质量验收，当前边界见待验收页。

平台品牌为 TruCreate / AI 创意设计平台，画布入口称为“自由画布”。使用分析按当前要求维持原有单页，不上线新版六页界面；具体发布与视觉验证边界见[待验收](/docs/progress/pending-test)。

## 一键图片工具与新模型

- “一键去背景”和“高清放大”有独立入口，也显示在自由画布选中图片后的右侧。普通使用者上传或选择一张图即可执行，不展示模型、提示词或参数；超级管理员可在 API 配置中独立维护两项工具，上传本人图片测试未保存草稿，再选择保存。任务冻结提交时的配置版本，后续后台修改不改变在途任务；结果另存，原图保留。
- 去背景由模型直接输出全彩透明 PNG，按管理员提示词保留主要主体、移除背景及无关物体；原图与模型结果分别保留，不将结果透明度套回原图，不承诺主体颜色、结构或细节逐像素一致。下载可选原字节透明 PNG 或同尺寸白底 JPG，格式转换不再调用模型；边缘、材质与文字仍需目视核对。
- 去背景可配置完整处理提示词，明确要求全彩透明输出。使用 GPT Image 2.5／2.6 时服务端固定 `background=transparent`、`output_format=png`；其他模型仅通过提示词要求透明输出，不追加不支持的参数，也不保证模型一定返回合格结果。高清放大使用管理员配置的受支持输出档并核验真实尺寸，未配置时沿用 Nano2.1／4K；去背景未配置时沿用 MAI。高清原件直通校验允许最多1800万像素，源图和普通合成的原限制不变；超限或不合格结果不冒充成功。原件已保存后的本地后处理失败单独提示、提供素材库与去重诊断编号，不继续上游回查或自动重生成；历史恢复须核对原任务与原文件，尚未完成的恢复不标成功。
- “提取产品图”是独立的托管入口，普通使用者只上传一张本人原图并查看结果；管理员独立维护模型、提示词与参数。未保存配置时默认使用 Flare 2.6／2K／medium，输出白底静态 PNG，允许为完整商品重新构图；补全遮挡属于推断，细字、配对数量、结构与材质需人工核对，原图不替换。
- GPT Image 2.6 Flare 标注“速度优先，适合快速迭代”，Sunburst 标注“细节与编辑一致性优先”。除去背景、高清放大与 MJ 专用融合外，通用图片、创意场景、系列配方及画布图片的新默认使用 Flare；用户有效的明确手选继续保留，文字和视频不套用图片模型。“切换生成图片模型”打开紧凑设置窗口，手机使用底部面板；切换模型时同步调整支持的参数，历史生成档案不被改写。
- 自由画布与普通图片入口可选 MAI Image 2.6 Flash：文生图 1K／2K、最多 5 张参考图，编辑时由模型决定约 100 万像素的 PNG 输出，不提供无效的编辑尺寸、4K、蒙版或透明背景参数。用于去背景时仅由提示词请求透明结果，不冒充 MAI 原生透明参数支持。
- GPT2.6 另提供复杂度、审核选项、纯文字 GIF 与独立透明 PNG 标注层；GIF 校验单帧及拼图尺寸，标注层须与第一张原图同尺寸且不能与蒙版混用。GIF 原件保持动画和原始字节，列表及画布使用有界动画预览；标注随输入档案与画布备份保存，不混入普通参考图。SVG 仍未开放，不能把渠道的纯文生 SVG 当作上传图片转矢量接口。

## 产品识别与设计接续

款生线稿、服装配色、局部改款、背面设计和花型提取可手动填写目标产品、位置与关键保留特征；也可主动点击产品识别，由后台当前对话模型分析一张本人上传的图片，返回最多八个候选，再由用户确认填入。识别可能产生模型费用，不随上传自动执行，不自动生成图片；候选名称与描述只是语义目标，不是分割蒙版。未明确的结果按原请求查询，不能因为网络中断或暂时查不到回执就再次收费提交。

创意结果卡显示实际输出尺寸、格式及分场景的人工核对项，不自动判定质量合格。选择“带入新草稿”可继续进入已有款生线稿、服装配色、局部改款、背面设计、花型提取或图片编辑，带入结果原图与可编辑的产品保留要求、材料和明确指定的颜色。原图、原任务与该板块原有草稿保留；新草稿按账号与交接编号独立保存，刷新不会把原始交接重复覆盖到新修改上。上一次的操作提示词、选区与模型不会隐式成为下一步的设置，不自动生成或扣费。

虚拟试穿要求产品图，可选成人模特图或模特描述；产品设计与模特姿态分别约束，输出不保证真实合身度或身份一致。线稿转实拍要求线稿、材质方向与颜色方向，可选材质配色参考图；参考图不能隐式改变线稿结构。两者拥有独立配置和草稿，不与托管产品提取共用配方。

线稿中的黑白线条不能恢复原照片未记录的颜色；色码不等于实物色差保证，背面或遮挡内容的补全也不代表已知事实。检查项是设计校对提示，不能替代打样、工艺或生产验收；原文件上传字节保持不变。

## 交互与编辑保护

素材库选择使用完整原图而非列表缩略图；多选确认按钮固定在图片网格下方，已选数量、读取中、失败与成功状态可见。创意场景的各图片位及系列配方的主／辅图位可直接从素材库选入，保留可获得的原文件名、图片名称／版本和来源身份；原素材不替换，不因选择而调用生成模型。没有图片位的以文生款不显示此入口。

用于生成的共享素材及团队提示词原图，须先确认当前员工有权读取，再按原字节建立本人私有副本；本人原图可复用原素材，缺件修复只允许本人原件。本轮将兼容模型的图片／视频参考与 LLM 看图预览统一为本域限时授权 URL，保留真实格式、大小、来源权限和任务／调用身份校验；缺少必要域名配置时明确停止，不静默改回供应商上传。蒙版、标注层和不支持 URL 的协议仍按各自契约处理，不公开整个素材库；供应商仍会取得所需素材，不宣称零外发或必然减少错误。目标端到端验收仍待完成。

APIMart 图片的上游错误文本在持久化前隐藏受控参考图的临时访问令牌，保留正常原因与原有凭据脱敏；任务暂停、恢复与素材权限仍按原流程执行，不通过错误报告额外提供原图访问能力。

图像及托管图片工具、十一个创意场景、视频、无缝拼接和系列配方可用“新建任务”打开独立页签，旧任务继续处理。图像和视频的记录栏“新建”及生成时的继续创作入口也创建独立任务，不清空正在运行的任务；主生成按钮在提交前后保持稳定位置，新增任务与查询按钮不占用原点击位置。每个任务保留自己的输入、参数、参考图、结果和原请求号；刷新只恢复或查询原任务，不自动重复提交。只有已结束且无待核查请求的页签可以关闭，关闭不删除原件与历史。并行提交仍受后台模型配额和实际服务能力约束，本地草稿也受浏览器存储容量限制；独立对话与画布助手仍使用原有会话机制。

独立对话与画布助手点击图片打开只读大图，支持缩放、平移、复位与下载原图，生成中也可查看。画布历史消息中已发送的参考图同样可打开原件；切换会话、项目或员工会关闭该预览，原件缺失时显示错误。查看图片不会改变编辑对象或未发送草稿；修改通过对话表达，不需要点击“继续编辑”或选择底图。切换账号会关闭旧图片预览和下载入口。

导航按创作、资源、协作、管理分组，图像子工具可折叠；常用入口由用户手动固定，不随访问次数跳动。首页提供全部工具、最近素材和收藏模板，最近画布基于本地画布与云端摘要合并显示，点击后才按需载入完整内容；手机导航保留工作台、主题与同步状态。平台名称为 TruCreate／AI 创意设计平台，画布模块为“自由画布”；用户自定义名称和原配色保持不变。

自由画布选中图片后，可用快捷“橡皮擦”直接进入本地编辑器，将经过区域擦为透明；支持调整笔宽、逐笔撤销／重做和取消。确认后另存透明 PNG 新节点，原图不变，不调用 AI。仍遵守本地工具开关、账号和画布编辑锁。

同一配置节点的侧栏与节点内提示词保持同步，提交取当前草稿；上传参考图期间切换画布、节点或新建工作区，迟到的上传不会串入新目标。图片和视频旧任务仍保存在自己的历史中，完成时不会覆盖新工作区或正在查看的其他记录。复制图片组同步重映射封面节点；缩放结束提交最后尺寸，未变化的尺寸不制造额外撤销步骤。

节点提示词编辑模块加载失败时，局部提示保留仍挂载的画布与当前页面，不自动刷新或重发生成。可导出既有画布快照、在新标签页恢复或关闭该编辑区；新页仍遵守编辑锁，不自动接管原页。页面保留不代表所有表单已保存或云同步，未提交表单需先自行复制，备份失败时保留原页。

HappyHorse 1.1 与 Seedance 2.5 支持随机种子，Seedance 另提供 MP4／MOV 输出选择；参数随草稿、历史及画布保存。MOV 原件保持原始字节，浏览器兼容预览另存，下载与导出不以预览替换原件。

创意场景及图案定位、花型循环、系列配方可分别固定到常用导航；桌面与手机沿用同一员工的选择和顺序，仍遵守原有功能开关。

查看图片、播放视频或浏览历史只切换预览，不覆盖当前提示词；需要复用时点击明确按钮，已有草稿会先确认。图片工具与视频草稿及参考图按员工、工具保存；未保存编辑受离页保护。有效会话使用期间按原有效期滑动续期。同账号会话过期时保留仍挂载的画布和草稿，不弹强制遮罩、不自动刷新；主动点击“恢复登录”后可在可关闭的面板验证同一账号，或在新窗口使用原登录方式进入。云端保存与生成仍需有效身份，过期时受保护请求仍被拒绝，不自动重发任务；OA 模式引导重新进入，不能把过期身份当成新的访客授权。

检测到身份变化时立即停止旧工作区，保存原账号本机分区并停留在明确提示页，不自动整页刷新；只有用户主动重新加载才重新验证新身份。迟到的旧账号请求不能重新打开工作区、回填结果或覆盖新账号数据。

生成区显示提交条件、参数摘要、各任务阶段和等待时间，错误提示与原始诊断分开。图片与视频支持参考图粘贴和拖入，结果可放入画布；重试采用原任务参数。排队或暂停任务只有在后端确认尚未提交上游时才允许取消，结果不明时查询原任务而不重发取消；停止本页查询不会撤回上游执行，也不承诺退款。创意历史仅允许确认删除终态本地记录，不删除原素材或正在跟踪的任务。

外部图片可拖入独立对话主区、图片／视频参考表单、创意与系列配方图片槽、无缝拼接原图区、素材库、设计灵感分享草稿，以及本地图案定位／花型循环工作台。画布主区域、空态卡和顶部栏接收拖入并导入节点，仍保留视频与音频导入；左侧创建区、画布助手附件区和配置节点参考图控件也可直接拖入，图片添加到对应参考区，不重复创建主画布节点。拖入仅导入素材或填入参考／分享草稿，不自动发送消息、生成或公开发布。单次外部拖入最多 20 个文件，仍遵守各入口更严格的数量、大小、角色和禁用条件。

读取支持浏览器提供的文件、只有 DataTransfer item 的原图及可访问的 HTML／URL 图片引用；空 MIME 根据图片字节识别，保留原件字节，不重编码。内部参考排序与普通文字不会作为外部图片上传，切换员工或编辑对象后阻止迟到导入。企业微信原生客户端的实际拖出行为仍待目标电脑验证；私有本地路径、浏览器不可读文件或受跨域限制的地址不能强行读取，可打开原图、复制粘贴或保存到桌面后再拖入。

画布提示词输入识别中文组字与重复按键；默认紧凑面板，导入内容避开展开面板，普通滚动用于平移，修饰键滚轮用于缩放。提供对数缩放、适应全部/选中内容及缩放快捷键；多文件上传有反馈并按网格排列，普通删除可撤销，裁剪改动与冲突副本有明确提示。完整平板双指和长按交互不属于本轮交付。

素材库保留查看、下载与更多操作，隐藏无意义零值，提供折叠筛选和完整筛选导出。导出读取所有分页及原始媒体字节，缺少原件、分页异常或身份变化时中止，不悄悄输出不完整包。提示词卡可查看全文，填入目标明确，查看或填入不会直接生成。

### 画布精细操作与轻量预览

画布支持多选成员的添加与取消、拖动阈值、Esc取消拖动或缩放、节点锁定、多选等比缩放、整组移动、对齐及分布。快捷键尊重文字编辑与中文输入法；多文件导入并发准备后一次插入，形成一个撤销步骤。连续方向键微移、整段文字编辑和节点操作分别保留清晰的撤销边界。

视频节点的画面区域可直接拖动并撤销；底部保留原生播放、暂停与进度条操作区。低缩放时可拖动海报预览，标题拖动继续可用，不改变视频文件或播放进度。

连线在低缩放下保留类型、箭头和屏幕宽度，反向连接绕过两端节点；悬停可选中、删除或拖动端点重接。重接失败或取消不丢失旧连线；拖动节点或连接线到画布可用区域边缘时自动平移，松手、Esc或窗口失焦即停止。连接下一步菜单按来源类型过滤并限制在屏幕内。

画布显示使用256、512、1024像素的分档预览，按实际显示尺寸、缩放和设备像素比选择，不因全局缩放超过200%就一律读取原图。本地缩略图以一个解码器和有界任务队列处理，超量请求等待，不以加载原图代替排队；离屏或取消请求释放对应预览。导入超过10MB或1600万像素的图片时提示轻量预览，原文件和下载原图保留原始字节；单张导入20MB上限不变。全尺寸查看、编辑和导出仍可能需要读取原图，不将轻量预览等同于无限内存或性能保证。

点选、平移和缩放不刷新作品更新时间或触发作品云同步。冲突副本有可比较的独立摘要，正式列表不为读取冲突提示加载整份画布正文；本地缓存与云同步失败分开呈现。跨标签页编辑锁、保存重试和导出备份保护已有作品，不自动覆盖另一设备的版本。

管理后台采用分组二级导航，账号可筛选并定位编辑行；模块、计费、价格发布、取消任务、账号与积分调整显示具体影响确认。积分对象、金额不预填；账号、服务、工作流、价格、配方切换时保护未保存内容。主要状态与时间采用中文说明和北京时间，权限不足或功能关闭显示原因。

## 产品动态与版本发布

正式登录后的首页显示最新已发布版本的标题、摘要和日期，导航中的“版本更新”可查看全文与历史版本。新版本以非阻断提示提醒，画布不自动弹出详情、不刷新或中断编辑；已读及已提醒状态按员工保存在当前浏览器，不承诺跨设备同步。没有已发布内容时不放置虚构公告，免登录试用与单机版不开放此功能。

此模块用于面向使用者的简洁产品动态，不自动公开仓库变更、配置、模型凭据或内部测试记录。数据库迁移不自动生成或发布公告，正式部署和首条公告仍需独立验证。

## 创作与任务

画布拖入图片、视频和音频，以及设计工作台保存工程和素材，统一兼容 HTTP 环境中的安全随机 UUID 生成，不要求浏览器提供仅安全上下文可用的 `crypto.randomUUID`。APIMart 参考图上传使用独立 ASCII 传输文件名，保留本地原名与原始字节；提交前规范 URL 中的中文、空格及裸百分号，不重复编码已有转义或改写签名参数。

复制截图后，在画布区域或左侧“描述图像”输入框按 `Ctrl+V`（macOS 为 `Cmd+V`）即可添加图片节点，同时保留正在输入的描述；直接使用本次粘贴事件中的图片，不依赖额外的剪贴板读取权限。多张图片依次导入并沿用上传图片的原文件保存方式。普通文字在输入框中仍正常粘贴；画布节点的复制粘贴保留，旧节点复制记录不会覆盖新复制的截图或文字。在“描述图像”输入框中，`Enter` 提交生成或生成修改图，`Shift+Enter` 换行；中文输入法选字和长按回车不会额外提交。

画布左侧创建面板在参考图上传、任务提交期间短暂锁定，服务器接收后即可继续提交下一项，无需等待上一项生成完成。每项任务独立保留提交时的提示词、参数和参考图；实际执行并发仍受服务端模型配置限制。

画布图片快生、节点生图和批量改图为新结果保存生成档案，包括原始输入、实际提交的最终提示词、模型参数及有序参考原图快照。点选图片会读取该图片的独立编辑草稿，并显示只读的生成时模型；下次生成模型单独保存，快速切换、修改参数、撤销和刷新不会把新描述或新模型写回原生成记录。上传原图或缺少历史证据的字段明确显示未记录，不以最近一次参数补造。左侧可展开、点击复制只读提示词，查看修改标记并恢复原始输入，还可查看及定位衍生图。更换模型保留已优化的文字、解除旧模型编译绑定；每次提交固定本次文字与参考图快照，后续编辑不串入在途任务。

“再来一张”使用档案中的最终提示词、原参数与原参考图，新增一张结果及连线，不把当前结果误作底图、不覆盖来源节点；原模型已不可用时明确中止，不静默替换。“基于此图继续”或在画布选中图片后按 `E`，只将当前图设为新参考并清空草稿，输入描述后才会生成。文本编辑器、弹窗和中文输入法仍优先处理自己的按键。参考列表完整展示实际提交项，原参考节点删除后仍显示保留快照，可逐项移除；档案与原图不会随参考列表移除而被删除。旧档案缺信息时明确提示，不能推断来源或保证找回丢失原件。

按住 `Alt` 拖动图片或选中组可创建副本，移动超过轻微点击阈值后才复制；副本沿指针移动且保留原名称、提示词与独立档案，不携带正在计费的任务绑定。连续 `Ctrl/Cmd+D` 沿用本次 Alt 拖动位移，切换来源后恢复默认偏移。每次拖出副本只占一步撤销；一次生成的占位、编译、结果和尺寸回填合并为一个生成步骤，期间用户的移动、草稿与参数修改仍可单独撤销。批量变体和独立版本分叉入口未增加；相同档案再次生成也不代表像素级复现。

图片、视频及共用生成任务观察的入口，在正式后端通过同一条 SSE 连接接收状态变化提示，再读取原任务快照；相同任务的并发读取合并。仍在观察的活动任务在后台保持推送，连接不可用时复用原观察循环的 2.5 秒 GET 回退，单机演示也保留此回退；普通非活动观察在页面隐藏时暂停，回到页面自动补查。推送和查询都不会重新生成；浏览器冻结、后台节流或断网时不保证三秒内更新。APIMart 图片与视频等待上游期间让出 Worker 执行槽，仍占用对应模型的在途配额，不突破后台并发设置。

本地观察期限到达后先读取一次最多 5 秒的最终快照；观察结束不等于上游任务失败。图片工作台和图片对话保留原任务记录，在页面可见时通过推送、焦点／网络恢复及 30 秒兜底继续只读核对；成功结果按原记录身份回填，不顶掉新建草稿或正在查看的其他历史，也不重复保存同一结果。手动停止查询、离开页面或切换账号会停止对应观察。

“刷新状态”只读取服务端原记录；只有已知上游任务号的暂停任务才提供“恢复原任务查询”，并须用户明确点击。提交结果未知且缺少上游编号时，显示待核查及管理员处理提示，不提供无效恢复、不自动重发或退款。已停用模型的既有成功结果仍可按原任务读取，不为恢复结果切换模型。

图片裁剪支持自由、原图、1:1、4:3、3:4、3:2、2:3、16:9、9:16 比例，拖动到边缘保持比例与图内范围；聚焦裁剪手柄可用方向键微调，Shift 加大步长。取消不改动原图。画布参考图选择取消或重开后清除未确认选择，已添加项禁用并显示标记。本地助手复用原附件数据展示已发送图片，关闭面板再打开不会因预览地址被释放而坏图。

独立对话与在线画布助手可直接说“继续改当前图”“回上一版”“用原图”或指定“图N”；底图、版本关系及参考角色在内部解析，不显示选底图、选版本或候选图片控件。图号稳定，默认从当前结果继续，明确指定旧版时按该版记录处理；原件缺失时停止，不悄悄换图。上传、图片预览与手工圈选仍保留，普通讨论不会自动创建图片任务，也无需先按检查按钮。

对话保留助手提出的方案、用户取舍及反馈，并把每版自身的要求与当前指令区分；旧方案不等于用户接受，历史要求不等于图片已实现。提示词将保留项锚定到本轮所选底图当前可见状态，历史相对变化不再次套用；本轮明确要求再次变化及合法静态尺寸、数量和比例仍保留。上下文有容量上限，长内容会明确标记节选；不承诺无限记忆。已确认需求卡、参考顺序、明确保留项和选区保护编入可查看的最终提示词，图片执行不再叠加私有对话改图配方，不自动扩写创意或翻译成英文。实际对话模型缺少看图能力时在计费与上游调用前提示更换模型，普通无图片 Agent 的文本接口不受影响。

生成结果可手动“检查结果”，使用该轮实际底图、结果与原要求，报告是模型建议而非像素级认证；检查不自动重画。“准备纠正草稿”保留该轮原参考与选区，已有草稿不会被覆盖，需用户发送才创建新任务。尚未提交任务的明确规划格式错误最多纠正一次；网络未知、隐私拒绝、已提交任务及图片生成失败不自动重发。手工圈选仍通过本地合成保护选区外像素，选区内效果需要核对。

画布图片快生、节点生图、局部编辑与角度编辑在提交前保存请求编号，服务器受理后立即保存任务编号。刷新或切换画布后返回，会查询原任务并回填原占位节点；提交响应丢失时按当前账号精确查询请求编号。暂停、查询异常或提交状态未知时保留原任务，“恢复查询”不会重新生成。明确失败或取消后才允许重新提交；停止本地派发不等于撤销已受理任务，正式后端拒绝取消已提交或提交状态未知的任务。历史帧本身不查询任务，旧记录没有任务绑定时无法自动找回。

本机 Mark 图片任务区分查询、下载与结果保存失败，保留脱敏错误码。已取得的结果地址只在服务端保存，恢复优先下载原结果；地址失效时只查询原上游编号，不重新生成。成功恢复后清除暂停错误，重复恢复已成功任务直接返回已有结果。

无线画布保留画布、创意设计、图片、视频、对话、素材和提示词操作界面。是否需要登录由部署开关决定：关闭 OA 不等于关闭独立账号认证；`AUTH_ENABLED=true` 时必须先登录。模型、任务、素材与历史连接服务端，模型凭据和敏感维护接口仍受保护。

## 直接使用与访问边界

仓库试用环境模板使用 `OA_LOGIN_ENABLED=false`；Windows 单机演示使用固定创作身份，完整后端的免登录模式使用浏览器访客会话。企业部署可以启用 OA、独立账号认证和员工云同步，实际边界以目标服务器配置为准，不能由试用模板推断公司部署免登录。旧员工数据不迁移或公开；免登录试用画布保存在浏览器，不承诺员工识别或跨设备恢复。

- 普通用户的创作界面不展示账号、小组额度或管理入口；已认证管理员始终可通过桌面侧栏、手机菜单与画布工具进入后台，不受普通角色门户开关影响。敏感后台仍要求管理员认证，免登录不等于开放管理权限。
- 模型 Key 留在服务器，真实生成仍可能收费；服务仅向受信网络或受控入口开放。
- 企业画布、原图、素材和任务按服务端员工身份隔离；试用模式不能验证企业隔离。旧账号与共用数据不自动迁移或公开，真实 OA 双员工和公司服务器仍待联调验收。

## 独立账号与可选积分

正式后端可设置 `AUTH_ENABLED=true` 使用每人独立账号密码，不依赖公司 OA。管理员从 `/admin/login` 管理，个人从 `/login` 登录并按要求修改初始密码。默认免登录试用不自动升级或迁移旧内容，单机演示不开放后台。

超级管理员可从后台“进入个人工作台”，使用自己的画布、素材、草稿和生成工具；个人内容仍以本人身份保存，不借用设计师账号，也不公开其他员工数据。部门管理员的访问范围不变。

独立账号模式完整配置企业微信后，个人登录页也可扫码，沿用已开通的设计师账号和数据；不自动创建账号，不为管理员开放扫码。企业 OA 模式仍直接复用 OA 身份，不增加扫码步骤。

- 管理员创建、停用、重置账号，支持 CSV 批量导入约 100 位设计师。
- 设置部门、角色、初始积分、每月固定额度，直接设置当月可用余额或临时加减积分；0 是有效值。
- 后台“账号额度”提供持久化的积分计费总开关，默认关闭；关闭不清空余额和价格，重新开启后按设置计费，仅超级管理员可切换。
- 操作价格与模型价格相加后在前端显示预估。
- 提交任务先冻结积分，成功捕获，明确失败按状态结算。正式后端只允许确认尚未提交的任务取消并释放积分；已提交、提交状态未知或结果保存未确认的任务保留原状态与预留积分，不因超时或本地取消而自动退款。已知上游 ID 的任务可继续查询原任务，不重新生成。
- `requestId` 保证幂等，同一任务不会重复扣费。
- 团队额度申请／归还在当前页面保留同一操作意图的编号，响应丢失后的相同重试不会换新编号；成功后刷新余额失败不误报操作失败。账号或小组变化隔离旧操作，明确打开新的已完成操作才重新编号；不承诺跨刷新保存该页意图。
- 账本记录调整、冻结、结算、释放及操作人。
- 开关对新提交生效，已受理任务继续沿用原价格快照；设置余额和加减分具有服务端幂等及权限检查。

## 服务端提示词优化与配方管理

创意场景、系列配方、图片工作流及服装模板的生成节点，先把表单、用户原文和有序参考图送到服务端编译，再提交实际图片任务。图片配方的每个版本可选择原有 LLM、最小改写或模板优先策略；确定任务可直接使用服务端中文模板，不调用规划模型，字段不完整或任务需要创作时回到最小改写。旧版本缺少新策略字段时保持原有行为，保存候选版本不会自动激活或覆盖当前配方。原有并行分支、串行工作流、权限与版本回滚保持不变。生成记录保留用户输入与最终实际发送的提示词。独立视频的智能动效仍按其视频配方编译，不套用图片模板。

- 普通图片、画布快生和配置节点默认按原文生成，只有点击“一键优化”才调用改写；优化结果先展示原文与改写对照，明确应用后才替换草稿。取消不改原文，中文结果不再后台另译英文。批量改图的优化默认关闭，开启时仅以第一张代表图改写一次，整批复用同一最终提示词。
- 参考图托盘可记录每张图的用途，上传、排序、生成档案和恢复均保留对应关系。自由输入提供实际发送文本及图片顺序预览；主站侧栏、手机导航和画布顶部共用“生成前确认”开关，默认关闭，开启后固定场景复用同一次编译结果确认提交，取消不创建图片任务。输入、图片、模型、账号或工作区变化会使旧预览失效。预览不收取图片生成费用，但需要 LLM 的编译仍可能产生规划费用。
- 反推提示词使用服务端配方，返回提示词与中文摘要。独立对话和画布助手只在执行边界组合本轮修改、明确保留项与图片职责，来源、替代关系和分支历史留在内部记录，不把整段历史治理说明发送给图片模型。保留项可查看和撤销；推断数量只作为待确认建议。统一对话模型配置、素材权限和原图身份不变。
- 无缝拼接、明确的细节增强与角度工具复用服务端固定短模板，不额外调用 LLM，用户补充要求按原样保留。自定义工作流和既有高清配方不被这些模板替换。局部改色/改款仍提示先圈选；整图生成不承诺区域外像素不变。
- 最小改写优先保留用户文字、数量、指定色值和参考图分工，不凭空增加 HEX 或未经确认的数量；明确数量与对象、左右部位的对应关系不能被交换，明确改数与纠正不当作新增猜测。保真校验失败或存在关键待确认问题时不提交出图。推荐字数是目标，不是截断用户要求的硬上限；这些语义检查不代表模型会严格保留原图的每个像素。
- 新策略作为管理员可选版本提供，不批量替换现有生产配方。[限额评测记录](../../../manual/prompt-optimization/testing/prompt-chain-evaluation.md)区分调用成功、视觉通过和待修正；缩短提示词不等于普遍提高质量。
- 扩写失败时默认不进入图片队列；只有超级管理员明确设置基础模板降级才会使用该模板，并标记为“未优化”。网络中断或上游是否收到请求不明时保留原请求待核查，不自动再调用模型。
- 参考图中的字样不要求用户先手动抄写；用户明确指定的文字仍须原样保留。模型报告的保留文字必须出现在最终指令中，这不等于独立 OCR 验证；生成成品仍需目视检查。参考图限额按实际目标模型校验，独立蒙版和标注层不冒充普通参考图；基础模板及历史缓存同样接受文字、图号与安全检查。
- 原请求查询遇到临时网络错误时继续保留“查询原优化请求”，不转为新的付费提交；输入、参考图、模型或工作区改变，以及页面卸载后，迟到优化结果不覆盖当前草稿。
- 同一账号的相同输入可复用扩写结果；版本、模型配置、字段、文字、参考图内容／分工／顺序、蒙版或语言变化均重新判定。原请求编号不能用于不同扩写输入，另一账号不能读取其记录。页面只展示最终提示词与安全状态，不返回配方原文、原始模型输出或内部版本规则。
- 超级管理员从 `/admin/prompt-recipes` 管理配方，独立绑定扩写模型、编辑草稿版本、激活或回滚，并查看延迟、Token 及成本。图片配方可显式出图对比；视频动效配方使用视频字段、中文摘要和视频目标过滤，不混用图片生成入口。空配方可创建首版草稿，保存不等于激活；初始化不内置或自动启用规则，未配置时停止调用。实际费用、配置估算和缺失费用分开记录，不把未知费用当作0，不直接相加不同币种。两组对话补充规则的实际行为仍通过对应对话入口验证。
- 正式后端使用 PostgreSQL；本机演示使用同一 `DEMO_STATE_PATH` 的 SQLite 保存配方和扩写记录，但继续禁止管理员登录与维护 API。首次部署须显式导入并绑定模型，未配置时停止生成，不自动启用或覆盖管理员已有版本。
- 配方导入追加场景保真约束：提取不默认补全缺失内容、工艺图完整入镜、线稿保留可见数量和遮挡、配色不重新设计结构。用户明确指定的印字支持常见引号和结构化文字字段，必须原样出现在最终指令中；有指定印字时将独立的笼统禁字项限定为无关文字。导入生成不可变版本，已有激活版本不会被自动替换，原始文档不改写。

这些约束提高指令与流程的可核查性，不保证模型像素保真、生产可用或每张图都更好。独立蒙版的原始供应商结果与应用无损合成结果分开评价。按项目所有者明确授权，原始方案和完整配方收录在公开源码仓库；网站运行时仍实行管理员权限隔离，但不能宣称仓库中的配方保密。

## Provider、模型与工作流

- 后台“模块开关”集中管理正式能力；“板块 API 配置”分组显示 AI 板块，包括 MJ 多图融合、创意场景、系列配方、画布生图／编辑／蒙版／角度／批量／对话／视频／音频、独立对话及其连续改图。总入口、本地工具和服务不虚构 API 配置；具体入口以当前配置为准。
- AI 板块可单独启停调用和设置费用总额覆盖。图片、视频等板块可独立绑定模型，留空沿用用户选择；独立对话与画布对话共用后台指定的统一文字模型，不提供设计师选型。绑定失效或关闭不会静默换用其他模型。留空费用沿用操作价加模型价，0 是有效总额覆盖；保存仅更新当前板块，编辑共用 API／模型必须进入明确标注的高级页。文字对话按每次成功模型调用计费，工具续答各算一次；总开关关闭时不扣分，明确失败、空回复或截断流返还。非 AI 本地工具不虚构模型扣费。
- 模块入口、API 独立开关和父级开关均生效；服务端提交时重新检查来源、模型能力与绑定，模型配置冲突要求刷新而不自动重发。后台更改会在前台下次配置同步后反映，已有历史、素材和本地备份不删除。
- 超级管理员在“API 配置 → 热门模型”选择最多 5 个已启用的 Mark 出图模型，并使用上移、下移调整展示顺序；保存空列表表示不展示热门模型，不会自动补满。普通接口模型始终保留在画布下方“所有模型”中，不自动加入热门；当前选中模型也不会改变热门顺序。此配置只影响展示，不更换配置 UUID、服务端凭据或板块绑定。本机免登录试用仍不开放敏感后台，正式数据库需执行 `029_model_presentation_settings.sql`。
- 管理 OpenAI Responses／图片、OpenAI Chat Completions、Anthropic Messages、Gemini、火山引擎、RunningHub、ComfyUI、自定义及内部 Provider。管理员在 API 配置中填写 Base URL 和服务端 Key，再为模型选择对应 Provider；Chat Completions 与 Messages 分别使用原生的消息、工具调用与结果回传结构。
- OpenToken 图片与对话模型使用该渠道的服务端 Key，图片可生成或携带原图编辑，文字模型由后台统一配置。旧配置与历史记录保留，前台可用列表以当前启用和绑定状态为准；实际型号、权限与费用由渠道决定，不将历史预置视为实时可用承诺。
- 画布网站 Agent 与独立对话共用后台指定的统一文字模型，设计师输入区不提供 LLM 选型；图片和视频仍按对应板块配置选择。模型凭据只在服务端维护，不在画布重复填写。
- API Key 只在管理员端提交，使用服务端加密密钥保存，设计师接口不返回原文。
- 模型配置包含能力、单次积分、人民币成本、并发限制和启用状态。
- APIMart 的四类图片模型按人民币单张总成本统计：GPT Image 2 为 0.05368 元，GPT Image 2.5 Flare、Sunburst 各为 0.1342 元，Gemini 3.1 Flash Image Preview（含 Official）为 0.3355 元。该固定表不包含 GPT Image 2.6 或 MAI，不能将 2.5 单价套用于新增模型。此规则仅限 APIMart 独立通道，优先于操作基础费和板块人民币覆盖价；其他模型与员工积分不变。新任务保存单价快照，成功后按实际保存图片数结算，重复结算不重扣，失败或未决任务不计为成功消耗；旧任务及历史费用不自动重算。此处是按配置单价统计的内部成本，不替代供应商实际账单。
- 后台生成历史、任务/核查记录、设计效能、团队生成明细和相关生图历史统一显示北京时间（Asia/Shanghai）；原始时间戳、排序和筛选请求保持不变。缺失、无时区或无效时间显示占位符，不用当前时间伪造历史。
- 出图列表保留四个 OpenToken 型号：`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`、`gemini-3.1-flash-image`，并追加已启用的 Mark 独立模型；下拉菜单保留简短用途说明。原有图片、对话、视频、音频配置与历史均不删除。
- 超级管理员通过“APIMart 平台”独立入口配置 API 地址、服务端加密密钥及该渠道的图片、文字和视频模型，包括 GPT2／2.5／2.6、MAI2.6 Flash、Nano、Grok、MJ Blend、GPT-6 Astra、Claude Sonnet 5.5 与 HappyHorse。它们不覆盖其他 API 的原有配置；同名模型使用不同配置 UUID，旧通道与板块绑定保留。逐个模型开关可独立设置，Grok2 新配置默认关闭；图片模型名后显示用途。各入口按模型显示真实参数：GPT2.5／2.6 画质和分辨率独立，Nano2 Official 支持 0.5K 而 Nano2.1 从 1K 起，MAI 编辑不发送尺寸，Grok 有参考图时不发送 quality，Blend 不显示提示词且只创建一个融合任务；已绑定工具仍服从后台配置。
- Mark 参考图由服务端上传后异步提交，独立蒙版使用 `mask_url`；任务编号持久化后再查询，恢复已知任务只查询原编号，提交结果不明不自动重新收费。HappyHorse 视频按 Mark 独立凭据上传、提交、查询与恢复；不混用旧通道密钥。正式后台配置已在隔离的真实 SQL 引擎和浏览器中验证加密、权限、幂等及重开数据库；演示服务不开放凭据写入。早期已实测模型的真实图片小样覆盖各独立图像板块，不包含此次 GPT Image 2.6／MAI 新增配置；视觉偏差与目标服务器未验项目另列，不承诺所有出图合格。
- 上述为默认出图列表；管理员为某板块显式绑定其他已启用兼容模型时，该模型会加入可用结果并用于该板块，不会因为默认四模型筛选而丢失绑定。
- 用途说明是选择提示，不代表独占能力或质量保证：直接描述生新图、快速探索设计方向、已有图精修；Gemini 按团队使用偏好标记为“前三个模型不合适时再试”，不是客观性能排名，也不暗示它是服装改款首选。能力参考 [GPT Image 2](https://developers.openai.com/api/docs/models/gpt-image-2)、[Flare / Sunburst 官方介绍](https://openai.com/index/introducing-chatgpt-images-2-5/) 与 [Gemini 图像生成文档](https://ai.google.dev/gemini-api/docs/image-generation)；不承诺原图像素完全不变，也不将官方全部参数视为渠道已支持。
- 管理员保留原始配置名称及展示名称对照，未入选图片配置仍可用原编号识别历史。四个已公开型号在选择器、历史和系统元数据中显示模型 ID；设计师请求及可恢复导出中的模型引用仍使用内部配置 UUID，参数按中性能力类型展示，不返回供应商配置或密钥。其他旧型号继续匿名显示，用户自行输入的提示词不改写。显示名称不参与路由，不改变实际 Provider 调用。
- 服务端验证任务类型与模型能力，音频任务不能误用图片模型。
- RunningHub、ComfyUI 和自定义工作流统一配置提交路径、状态路径、模板变量、成功/失败值与结果路径。

## 常用板块与使用分析

- 首页最近使用与已保存的固定入口仍遵守模块和工具开关，不让快捷入口绕过权限，也不挤占侧栏核心入口。导航偏好、本地访问计数与待上报事件按员工分区，切换身份不会沿用另一员工的数据。
- 超级管理员在后台独立的“使用分析”页使用原有单页界面：日期与用户筛选、简要汇总、每日趋势、模型与板块分布、人员列表及个人明细。默认入口直接加载原面板，不提供新版六页切换；普通用户和部门管理员均不能查看这些人员数据。
- 模型统计以实际任务和文字请求为准，点击模型选项不算调用，恢复旧任务不重复计数。访问、操作、请求、成功与失败分开显示；成功率等仅反映软件记录，不评价员工能力或绩效。
- 人员搜索（姓名或账号）和起止日期共同作用于汇总、人员列表、个人明细、导出与分析预览；日期包含起止两天，固定按北京时间计算，生成记录按首次提交时间归入周期。汇总覆盖全部匹配记录，不受当前分页限制。
- 提供今天、近 7 天、近 30 天、本月与上月快捷日期，以及板块、已记录模型筛选；点击有效分布项可下钻。筛选尚未应用时，旧结果明确标注并禁止按新条件导出或分析；切换筛选清除旧个人详情和分析预览。
- 总览与个人详情展示每日模型请求、实际出图、已记账生成费用或终态成功率，并可展开准确数据表。终态成功率为成功除以成功与失败（含取消／中断），未完成不参与，无终态请求显示空值；空白日期不推断为未使用。人员表按费用、出图、调用、失败或最后记录在服务端排序后分页，保留零记录员工，不显示绩效名次。

## 对话改图与附件

- 独立对话与画布助手采用受限阅读宽度、完整比例图片和稳定的底部输入区。新内容仅在接近底部时跟随；上翻阅读保留位置并提供新消息入口，图片晚加载仍可跟随。
- 结果图及大图预览可点击“复制图片”，再在下方输入框粘贴为图片附件，不自动发送。支持系统图片剪贴板的地址可向其他应用粘贴；HTTP 等受限地址使用同页复制并明确提示范围。同页粘贴使用原始文件字节，保留普通文字的原生粘贴；刷新、切账号或新的复制会使旧图片引用失效，仍受当前附件大小与数量限制。
- 只改蝴蝶结等局部时，先涂选修改区域；现有合成保护选区外原图。未涂选的整图参考编辑可能重绘面料光泽和纹理，2K／高画质不能保证未改区保真；已经偏移的结果应回到材质正确的原图再改，不自动猜测选区。

- 上游拒绝会按已确认的状态与安全原因类别提示下一步，例如检查素材、上下文、参数或账户权限与额度；服务端只记录HTTP状态和固定类别，不暴露可能含凭据的原始错误正文，也不自动重发。本地演示服务的配方配置失败保留明确提示，不再误报为参数错误。Sonnet的两条历史400已对应到Bedrock账户模型访问被拒。当前v3/v4载荷审计确认协议形状、模型和图片相同，v4仅缩短文字及请求体；本地纯文字、带图和完整v4各一次受控请求成功，正式原账号另一次纯文字请求成功。不换模型、不发工单，也不以这些成功对照宣称历史拒绝已长期根治。

- 独立聊天支持 Markdown、表格和代码块，可复制原文、编辑原消息或重新生成；编辑和重新生成建立新分支，保留原会话及后续消息。模型写入的原始 HTML 不执行，外部图片文本仅显示链接，不自动请求外部图片。
- “停止”结束本页响应或任务观察，不承诺取消已受理的图片生成。停止后的图片任务保留原编号，刷新后不会自动重新开始查询；点击“查询原任务”才恢复观察，不重新付费提交。未核实的图片任务先恢复原任务，不能直接作为新生成重放。
- 聊天图片以本地文件键保存，逐会话记录仅写入变化的会话；打开旧记录时按需转换并保留旧快照。草稿、聊天和素材持有的图片不会被普通本地图片清理误删；这些独立聊天数据仍属于当前账号的浏览器存储，不承诺云端同步。

- 独立“对话改图”、画布对话、产品识别及使用分析跟随后台统一文字模型，本轮目标为 APIMart Gemini 4 Carbon（`gemini-4-carbon`），已接入文字、看图和工具调用；配方的 LLM 绑定随本轮业务配置一并核对。管理员仍从“API 配置 → 板块配置 → 对话改图 → 统一对话模型”切换，配方维护入口保留；设计师端不显示 LLM 选型。新环境默认不覆盖已有管理员选择，生产切换须独立确认，不替换图片或视频生成模型。
- 服务端以 `gpt-chat.modelConfigId` 为唯一对话模型来源，不接受浏览器、旧会话或旧节点覆盖；`canvas-chat` 的模型继承它，开关和费用仍单独生效。未指定模型，或模型、API 服务不可用时明确停止，不自动换用其他模型。管理员可选择已启用且服务可用的文字模型，历史记录不删除。
- APIMart Sonnet 按 [Claude Messages 文档](https://docs.apib.ai/cn/api-reference/texts/general/claude-messages) 接入 `/v1/messages`，GPT-6 Astra 继续使用 Responses；通用文档的协议核对和本地模拟验证不等于指定模型的真实可用性或付费验收。
- 对话出图仅提供支持文字提示词的图片模型；无提示词的多图融合模型保留在独立融合／画布流程。旧会话误选融合模型时回落到兼容候选；后台若明确绑定了不兼容模型，则停止出图并保留纯讨论，不跨供应商绕过绑定。
- Claude Messages 的 `anthropic-version` 使用 [Anthropic 官方版本](https://platform.claude.com/docs/en/api/versioning) `2023-06-01`。规划和提交期间暂时占用发送入口；图片任务受理且原任务标识落盘后释放输入，等待在独立卡片中继续。纯文字回复完成后立即落盘；保存失败保留可见回复并提示复制重要内容，避免把“已返回”误当作“已保存”。
- 正式对话的传输失败区分“业务请求尚未发送”和“请求可能已发出、结果待核查”，不自动重发；响应正文中途断开也保留安全诊断，不误归类为普通 JSON 格式错误。上游已返回部分内容时保留可见内容并提示核查，不把原始凭据或代理地址暴露给客户端。
- 独立对话与自由画布助手均可上传 PDF、Word（DOCX）、Excel（XLSX/XLS）、CSV、Markdown 和普通文本资料。原文件字节、完整分节、图像预览及需求卡分别保存，按员工和会话隔离；新增文件不会自动发送或生成。每会话最多 8 个文件，单文件最多 20 MiB；超过 200 节或 100 万正文字符时明确要求拆分，不把截断文本冒充完整文件。独立对话每次最多添加 5 个附件；图片仍限单张 5 MiB、本次合计 8 MiB，粘贴原始字节保持不变。
- PDF 按页读取文字并渲染页面预览，扫描页可按图查看但不执行 OCR；DOCX 按正文、表格、注释及内嵌位图读取，不承诺原分页、页眉页脚、浮动图形或修订完整还原。Excel 保留工作表、坐标、合并范围、隐藏表和公式缓存，不执行公式、不读取外链；内嵌图片／图表仍需另附。XLS 支持可读取的 Excel 5–2003 CFB 工作簿，其他旧格式或加密文件须另存 XLSX。预览最多 80 张、24 MiB，遗漏和未支持内容明确提示，原文件不裁剪、不重编码。
- 助手先看到文件目录，再按页／节、关键词或长节字符游标查阅，每次返回不超过 18000 字符并标明真实来源和后续游标；预览摘要不代表已经看过全文。提炼的需求卡列出主体、颜色、材质、必须／禁止项、待确认项和出处；用户可编辑并明确确认。仅已确认内容进入后续规划和生图参数，修改后重新待确认；待确认项不变成确定要求。可选择文档中的图作参考，自由画布可把已确认需求卡放成文本节点，不自动出图。
- 文字、文件正文和图片在同一条对话中理解；新图片可作为修改对象或辅助参考，不直接清掉历史图片。历史文字请求最多携带 24 条消息、48000 字符，另提供最多 40 项图片目录与最多 28000 字符的当前图片执行条件；每次预览最多 5 张、8 MiB。截断会标记，浏览器内的完整历史不会因请求窗口缩短而删除。
- 独立对话改图页面的聊天记录与已发送附件内容通过 localforage 保存在当前浏览器的 IndexedDB，企业模式按员工分区，刷新后可继续问答但不代表云同步；画布内聊天随整张画布保存，企业模式参与云同步。保存失败会明确提示，发送前保存失败时保留草稿和附件；旧版仅保存的文件名无法还原已经丢失的附件内容。
- 独立对话的资料与需求卡随本机员工分区会话保存，自由画布的资料随现有画布文档与媒体同步；不会由需求卡建立跨会话个人行为记忆，也不自动读取其他会话资料。
- 自由画布仅上传文件、尚未发送消息的会话也会出现在对话历史中，可按显示的文件名摘要搜索并重新进入；真正空会话不占历史列表。切换和刷新沿用已保存资料，不自动重新解析、理解或生成。

## 连续图片创作

- 对话改图只有一个发送入口，不再区分聊天、创作或 Agent 模式，也无需选择理解模型。未明确选图时仍可直接上传图片或要求文件并说修改需求，后续只发文字即可继续；普通问答、资料分析、提示词整理、生成和改图由后台指定的同一对话模型判断。
- 两端的模型目录使用稳定“图N”，界面按作品显示版本和当前标记。当前图常驻输入框上方，支持原图、上一版和新创作；点图片或 `@` 选图会锁定底图，发送后仍保留到该轮结果完成或用户主动切换。卡片操作在悬停或键盘聚焦时出现，更多菜单保留下载、对比及各入口原有操作。“作为参考”只补充参考，不自动替换底图；这些选择不调用模型，仍须发送文字。
- 本轮明确选定的底图在执行前校验，不允许模型悄悄换成另一版本。新请求不创建旧编辑合同、不进行合同修复或额外翻译；既有记录和来源证据保留为历史，不据此重发旧任务。切换会话、画布或员工后不携带另一作用域的选择。
- 回原图按实际保存的来源定位，不猜第一张上传图；来源断链、循环或原件不可用时禁用并说明。多原图对比要求手选，比较界面不会创建真实画布节点或调用 AI；下载沿用原件字节与真实格式。两端共用焦点、工作集和作品说明内核，但不迁移、合并或互通各自的会话存储。
- 这是应用组合模式：对话模型规划，图像模型通过已有任务、服务端会话和素材链路执行；内部积分由后台总开关与对应板块价格决定，对话续答与图片工具分别计费。它不是 Responses 原生 `image_generation` 工具。当前 OpenToken 实际接口拒绝该原生工具，不能把 OpenAI 官方支持直接等同于渠道支持。
- 上传图与生成版本的稳定身份、真实来源和上次结果随会话保存，存储位置沿用两端原有边界。代码选择默认当前图，模型只理解修改意图和明确的版本方向，可以自然表达“改刚上传的这张”“回到原图”“只参考这个颜色”。指代不清时简短追问并提供可点击候选，不凭空猜图；查看未预览历史图是只读动作，不循环生成。
- 独立对话将本轮修改、仍有效的保留条件和参考图分工共同编入实际图片请求，不再只保存保留项而漏传给出图模型。参考图按稳定图片身份映射到本次传图编号；排除图、歧义编号、无效约束及超过 20000 字符的完整指令在提交前阻断，不静默截断或换图。明确撤销的条件不再执行，不把其他历史分支或生成成功自动视为用户认可。
- 原始工具 JSON 在转换为对象前拒绝同一对象内的重复字段，防止只留下最后一项而静默丢失约束；不会自动合并坏参数或重试付费调用。已经由上游转换成对象并丢失的信息，客户端无法追溯恢复。
- 实际底图、输入顺序、最终提示词、任务响应和成图分别核对。正确选择底图和成功返回不等于视觉保真；未圈选的文字改图可能重绘纹理、明暗或比例。独立对话可手动涂选需要修改的区域：支持原生蒙版的模型沿用原生蒙版路径；Nano2等已支持参考图编辑的模型使用原图与蓝色选区示意，返回后按选区合入原图并保留选区外像素，不冒充原生蒙版。选区与底图绑定，比例冲突或记录不完整时停止；合成失败保留原任务，恢复素材后查询，不重新生成。选区内结构、接缝与光影仍需核对，不会自动识别并保护用户未圈定的全部区域。
- 图片模型沿用会话或现有配置，按生成/编辑能力自动选择，不要求用户每轮配置两个模型。纯讨论不提交图片任务；仅上传而没有文字要求时先读取内容，不直接执行文件正文中的指令。每轮最多一个图片任务；没有图片服务仍可正常问答，只有实际需要出图时提示服务未配置。
- 出图模型、画幅、清晰度和质量收在“出图设置”中，主界面只显示当前图片模型。画布设置弹层随窗口移位并限制高度，参数较多时可在弹层内滚动，关闭重开保留草稿与选择。独立对话默认“自动”，模型支持时直接使用自适应画幅，不支持自动的模型在编辑时选择最接近底图比例的支持尺寸；不承诺原始像素分辨率。主动选择的画幅随会话保存并优先使用，不支持的手动比例仍在提交前提示。画布对话继续跟随底图，比例匹配允许整像素取整误差。选项按模型能力显示，不修改其他页面的全局参数；高画质不等于更高像素尺寸。规划文字流式显示，图片任务仍需等待上游完成。
- 所有新上传保留原始文件字节，实际编辑使用原图；历史上已压缩的旧附件无法还原原字节。完全重新创作使用 `generate`，不传旧图或建立虚假父链；依赖参考图的创作使用 `edit`。图片来源与保留项是执行记录，不代表视觉质量或未修改区域逐像素一致。
- 会话保存模型、图片结果、完整执行提示词及图片来源关系；保留各版，不覆盖旧图。图片的“放入画布”会创建或复用该会话对应的画布，保留原始比例；企业模式按员工同步画布，试用模式本地保存。重复点击或保存失败后重试不会新增相同节点。
- 生成前保存失败保留草稿；规划或上传期间离开页面、切换账户，会停止尚未提交的任务准备；已提交的任务继续由服务器执行，不会因为页面退出重新提交。
- 出图过程中刷新，依据已保存的请求或任务 ID 只查询原任务，成功后将图片及来源关系恢复到原会话、原消息。状态未知、暂停或找不到任务时保留待核查提示，不自动重新生成；同会话可以继续聊天或提交不同任务，仅相同未核实输入被阻止。停止卡片等待不撤销服务器任务，迟到结果不自动落图；之后可按原编号继续查询，且不抢走用户后来选择的当前图。

## 图片、视频与音频

## 自由画布与批量改图

- 选择批量原图后可继续输入提示词或调整参数，等待组件加载不会丢弃已选文件；连续选图采用最新列表。清空列表、切换批次或离开画布后，迟到的文件准备结果不会写回新输入。

- 批量改图可在原批次尚未完成时点击“新批次”，每批独立保存提示词、参数、原图列表、进度和服务端批次号；切换批次或关闭窗口不取消任务，暂停／恢复／取消只作用于当前选定批次。已提交的输入与结果保留，下一轮从新批次开始，未知请求不重复提交。批次列表只在当前页面内管理；刷新或离开后，按已保存的画布节点和原请求号恢复查询，不自动重新生成。
- 单张图片下载可选原文件、PNG 或 JPG；PNG 保留透明，JPG 将透明区域填为白色，转换保持原始像素尺寸。框选多个节点后，画布工具栏和节点右键菜单提供“下载所选图片”，显示可下载张数，默认仅将所选图片打包为原图 ZIP，忽略文本等非图片节点，不带入未选图片；也可切换 PNG／JPG／PDF。导出图片集仍可从左上角菜单选择全部图片。这不是将整张画布合成为一张图片，不改动节点或原件。

- 画布顶部、弹窗、节点／连线图层与快捷键、历史、持久化、剪贴板和生成运行状态分别维护。每个编辑器拥有独立的 Zustand 图状态，节点按 ID 订阅自身与流式文本；悬停和逐字流式更新不再使整个编辑器订阅这些高频状态。

- 图片工作流由画布上的真实连线定义：原图连接第一个生图配置的左侧，从配置右侧拖线到下一个生图配置左侧，或拖到空白处新建配置节点。各节点独立填写提示词、选择模型与尺寸，直接点击节点上的“运行工作流”即可按依赖执行，无需先分组或进入弹窗。支持串联和一个上游连接多个下游的分支；每个节点只接受一个上游图片，分支各自使用其父节点的结果。循环、多上游及缺少原图会在提交前阻断。
- 图片“更多工具 → 图片工作流”只是快捷搭建入口，可预填“抠成白底 → 改成紫色 → 模特上身”并生成 1–10 个横向连接的配置节点；添加不调用模型。最终执行顺序以连线为准，不以节点位置、组内列表或创建顺序为准。原图和中间结果保留，运行记录可从组标题查看。
- 配置节点互不重叠的图片工作流可以同时运行，每条流程内部仍按依赖顺序执行；同组、交叉配置节点和普通节点生成保留互斥保护。停止只作用于指定流程，关闭窗口不停止任务；运行中的相关连线不能修改，不阻挡其他独立流程的连线操作。
- 工作流失败即停，不自动重试；“继续工作流”在连线和参数未改变时跳过已完成步骤，优先查询未决的原任务，结果不明时不盲目重提。完成后再次运行，或修改连线与参数后运行，会创建新的一轮。流程随画布保存；刷新、离开或关闭页面不会自动执行后续步骤，重新打开须手动继续。每步单独计费，停止不保证撤销已提交的服务端任务。当前是图片节点工作流，不兼容 ComfyUI 的插件／工作流文件，不支持多输入合并、多结果自动选图或后台无人值守。
- 模板窗口可编辑流程名称、三个步骤名称及提示词，保存为“我的模板”；支持更新原模板、另存一份，以及关闭／刷新后再次复用。个人模板按当前员工保存在本浏览器 IndexedDB，暂不跨设备同步，清除网站数据会丢失；保存失败保留编辑内容，不覆盖原记录。保存模板不添加节点、不调用模型；应用时绑定本次选中的参考图，更新模板不改变已添加的画布流程，内置模板保持不变。
- 底部“自动整理排版”可网格整理、顶部／左侧对齐、横向／纵向等距排列；有选区时处理选中内容，无选区时处理整张画布。款式组和批量图保持整体移动、保留组内布局；操作可撤销并跟随画布保存。
- 多选至少两个节点，点击底部“创建款式组”、右键同名菜单，或使用 `Ctrl / Cmd + G` 创建款式组。组标题支持重命名、拖动整体移动、折叠／展开与取消分组；分组不是图片合并，折叠只隐藏成员及相关连线，取消分组保留全部内容。批量图片作为整体归组，分组和成员移动支持撤销／重做，完整复制组内成员时保留分组并生成新 ID。
- 款式组随整张画布保存、企业云同步和画布 ZIP 导入导出，包含名称、成员关系与折叠状态。折叠组内未选中内容不作为助手的可见画面自动读取；明确选择的素材仍可作为上下文。
- 图片节点根据实际显示尺寸、缩放和屏幕像素密度选用 256／512／1024 像素预览，接近原始尺寸时切回原图。预览缓存按员工隔离，最多保留 128 份，后台单队列生成；格式不支持或缓存失败时回退原图。此优化只影响画布显示，不改写图片内容、编辑源、导出文件或云端原图，也不承诺所有设备或首次解码均更快。
- 画布包含节点位置与尺寸、连线、文字和编辑内容、图片／视频／音频及参考图、画布内聊天、最多 50 步撤销／重做历史和视口。企业模式先写员工分区的 localforage / IndexedDB 缓存，再上传原始媒体并同步服务器文档；试用模式只保存本地画布。保存不缩放或重新编码原图，手动编辑结果按现有字节保存。
- 企业页面区分本地保存与云端同步状态；失败保留待同步内容，不伪称成功。确认已同步后，同一员工可从公司 OA 重开或换设备恢复；不同设备写入使用版本校验并保留冲突副本，删除墓碑防止旧设备复活，不是实时协作或无限历史。
- 试用画布、未同步内容、独立聊天和创意草稿换环境前需导出或另存，不清理网站数据、不用无痕会话保存重要作品。分享链接不授予员工访问权；旧账号与共用数据不自动迁移、删除或公开。目标公司环境的恢复和隔离仍需实测。
- 画布本地自动保存尚未完成时，刷新或关闭页面会立即尝试写入并请求浏览器显示离开确认；取消离开可继续等待保存。强制离开、崩溃或断电仍可能丢失未落盘改动，重要内容应导出备份。
- 图片平时不显示常驻边框、阴影和圆角裁切；悬停显示细边框，选中才出现缩放控制点和快捷工具，点击空白处隐藏。默认快捷工具为“编辑图片／AI 编辑／下载”，局部重绘等次要操作在“更多”中，已自定义的快捷工具仍保留。连线点在选中并悬停或连线过程中显示，常规流程节点的连线入口不变。
- 画布工作区使用中性灰白背景、点阵网格、左侧创建面板、左上项目菜单、右上工作区信息和底部浮动工具栏，深色模式沿用同一套灰阶主题。模型入口放大，模型面板按品牌图标、用途及实际支持参数展示，打开时展开并定位当前模型。比例、画质菜单从按钮下方展开，短窗口中创建区让出下方空间；“更多设置”打开宽大窗口，使用分区卡片与可直接点选的参数选项。菜单和窗口均有明确的返回入口，关闭不会清空提示词、参考图或已设置参数。每个图片任务仍固定生成一张，不虚构价格、耗时或未接入模型。
- 打开已有内容的画布时，创建面板默认收成紧凑入口；桌面空画布仍展开。面板可手动折叠，点击或框选图片不会强行展开，仍自动更新参考图。“AI 编辑”可带参考图重新展开创建面板。取消选中不清空参考图草稿；背景和图片信息集中在底部“更多工具”，对比、模板和排版集中在“设计工具”。左上菜单和底部“全部工具”保留现有板块，可搜索进入，仍遵守原有模块与权限开关。窄屏从“更多工具 → 画布生图”展开创建区。
- 桌面创建／窄栏对话面板默认宽 480 像素，字体与按钮同步放大。“大小”入口提供宽度滑块、紧凑／舒适／宽敞预设，创建区还可调输入区高度；也可拖动右边缘调宽，标题区域同步对齐。两种面板分别记住本机宽度，双击边缘或聚焦后按 `Home` 恢复默认，左右方向键微调。创建区内的长内容独立滚动，底部参数和生成按钮保留可见。
- 画布左上角菜单提供“导出图片集 / PDF”。可导出全部图片或当前选择，勾选后按上下箭头调整顺序，并填写图片集名称；支持一个多页 PDF、每张一个 PDF（ZIP）或原图 ZIP。批次封面自动展开为实际子图，不重复导出封面。每批最多 200 张、原图合计 256 MB；PDF 单图最多 4000 万像素，每张图独占一页，按原图比例设置页面，不拉伸或裁切。PNG/JPEG 直接嵌入，其他可读取格式转为静态 PNG；原图 ZIP 不改动文件内容，某张读取失败时整次停止，不交付缺页文件。
- 图片上传默认沿用文件名，可从节点右键菜单“重命名”修改名称；显示图片信息时可见名称与版本。初始版本为 v1，手动编辑或基于参考图生成的结果沿用来源名称并递增版本，多参考图以第一张为准；重命名本身不增加版本。图片下载及图片集内文件使用“名称_v版本.实际格式”，ZIP 中额外加顺序编号避免同名覆盖，PNG 编辑结果不会因来源为 JPG 而丢失透明通道。
- 新图片拖入、文件选择、粘贴以及画布参考图和批量上传均限制单张不超过 20 MB（20 × 1024 × 1024 字节）；超限在保存或上传前拒绝并提示，不自动压缩，不删除已有图片，也不影响生成结果归档。图片还须成功读取真实尺寸；空文件、损坏文件、读取超时或下载失败不会保存成占位图片，也不使用虚构尺寸继续编辑。
- “编辑图片”新增自定义宽高，支持 728×90 等正整数像素尺寸。最长边不超过 8192 像素、总像素不超过 2500 万；默认等比缩放并透明留边，也可选等比居中裁剪或明确拉伸。尺寸变化支持撤销／重做，保留透明通道；这是本地图片编辑，不调用 AI，也不改变模型本身支持的生成尺寸范围。
- 生图工作台的历史结果卡和“我的素材”图片详情提供“编辑原图”，可恢复本地保存的原始图片直接修改。保存会另存为当前用户的新素材版本，原生成记录、原素材与原图均保留；新版可重新插入画布继续编辑，名称和版本信息跟随传递。此处的版本用于同源结果标识，不是覆盖式历史回滚系统。
- 独立对话改图与画布助手内部保留“当前图”：默认接着最新成功结果改，通过自然语言表达“上一版”“最初原图”“图3”或新作品，不要求用户操作底图或版本选择器。上传配色等参考不自动替换已有作品，缺失素材不会偷偷换成另一张；反馈“改错了”本身也不自动回原图。

- 两端自然历史最多保留最近20条、合计48000字符，较早内容有界摘录；生成图片在原消息位置标记图号。工作集按显式引用、当前图、原图及上一版选取，最多5张、长边约1024像素且总预览字节受限；原件仍用于编辑和下载。较早图片可通过只读 look_at_images 按需查看；若模型直接选中尚未预览的合法旧图，提交前先读取该图及本次必需参考的真实像素，再进行唯一一次规划修正。读取失败、超限或取消时不提交生图，不把全历史图片混入生图输入。

- 服务端素材、任务、批次与历史按游标分页，默认 60 条、最多 200 条；列表仅保留展示摘要，完整提示词、参数和输入归档在打开／复用时获取。素材库、管理任务和历史滚动到底自动继续加载，失败时保留手动重试；公司素材的设计师筛选由服务端执行，不限于已载入的第一页。新结果刷新后位于前面，恢复原任务不受分页截断。
- 素材库支持复选、Shift 连选、`Ctrl/Cmd+A` 选择当前已载入项（最多 50 项），底部可批量删除、ZIP 下载、加入画布或移动项目。一次批量请求先验证全部权限再执行；未获权限的混合选择不会部分删除。演示模式的项目同步和移动结果也写入本机 SQLite。
- 素材库增加标签、日期与时间排序筛选，并提供 30 天回收站；恢复前确认权限、期限和原文件仍存在，重复来源冲突不覆盖现有素材。并行上传逐项报告结果，失败项可单独重试；下载及分享更新不重新加载整页。
- 上传与生成图片异步建立两档 WebP 缩略图，原件保持不变。缺失缩略图由数据库待办持续领取，每个 API 最多 2 项并行、单项最多 4 次尝试；退出归还、重启恢复，失败时仍可读取原图。原文件采用流式响应，先验证当前用户权限再处理 ETag；缓存必须重新鉴权，切换身份不能借 304 绕过访问限制。
- 生图结果卡和历史小图使用显示专用的派生预览；服务器素材读取授权缩略图，本地图片复用员工分区预览缓存。打开大图、编辑与下载继续使用原文件，历史小图进入可视范围后才读取本地图片。
- 画布图片缩略图读取失败时自动尝试原图一次；原图仍失败时显示“图片读取失败”和“重新加载”。手动重试只读取图片，不改变节点或提交生成任务。正式原件与缩略图接口支持单段字节范围读取，客户端断开会终止上游读取；不支持多段拼接响应。

- 网页参考图采集内置于画布右上角，点击进入独立审核页，可返回原画布；素材库也有入口。粘贴公开 HTTP／HTTPS 网页链接即可采集，无需插件，先预览和勾选，确认后才写入当前员工素材库，不占用图片工具栏。原始文件不压缩、不重绘；支持 PNG／JPEG／WebP／GIF，每批最多 20 张，单张 10 MiB、总计 30 MiB；单张失败单独提示，取消采集不会自动入库，来源记录移除查询参数和片段。仅解析公开 HTML，不执行网页脚本，不携带登录凭据，不能访问内网、非标准端口或绕过网站限制；临时采集记录 5 分钟过期，页面草稿刷新或离开即丢失，使用者须确认保存权限。
- 网页扫描最多列出 100 个候选，选择最多 20 张后才读取图片预览，再确认入库；读取与上传分别限制并发。单张失败不阻断其他项，重试跳过已完成项，账号变化立即停止后续写入。
- 网页候选绑定实际扫描输入；更换链接或开始新扫描立即撤销旧候选，旧响应不能覆盖新链接结果。读取前再次核对来源，已有待审核或已导入草稿不因换链接被删除。
- Chrome 采集扩展仍是可选补充，安装说明默认收起。扩展扫描浏览器当前网页并仅请求画布与所选图片域名权限，再送入同一审核页；不保证能读取登录或防盗链图片，不自动翻页、不采视频。安装说明见审核页及 `tools/chrome-reference-importer/README.md`。
- 普通生图／参考图改图的新记录保存版本化输入归档：原始提示词、模型配置、生成参数与有序参考图的原始文件及校验值。恢复时先检查员工、模型可用性和全部原图，成功后才填回草稿，不自动生成或收费；原图缺失／变更、权限变化或旧记录没有归档时明确提示，不静默替换成当前图片。图片工作台可显式“恢复为草稿继续改”，画布从生成结果的图片菜单新增恢复配置；普通画布不把蒙版或专用工具任务降级为普通改图。创意场景另行保存本地原图与选区副本，不承诺跨设备恢复；缺失文件暂无补传恢复入口。恢复输入不保证再次生成相同画面。
- 上传图片、视频和文本，生成结果自动进入服务端素材库。
- 素材库、个人/共享提示词及管理历史保留当前会话中的输入或筛选状态；图片/视频创作草稿与参考图使用员工及工具分区的浏览器持久存储。切换身份不会载入另一员工的草稿；保存、复用和生成操作有重复点击保护与失败提示。
- 服务端素材的标题、标签、来源说明和备注通过带权限检查的接口更新，保留原始文件和生成信息；浏览器本地素材仍保存在本机，不与服务端素材混写。
- 个人与共享提示词按服务端总数分页查询，不再仅展示前 100 条；编辑时保留视频时长、模式等未显示在通用表单中的参数，保存失败保留表单内容。
- 提示词库新增独立“通用提示词”分类，内含24项原创中文模板，覆盖商品处理、服装配饰、图案工艺、场景展示和视频动效。支持按标题、全文、分类与标签搜索，查看完整文本和方法来源、复制、填入对应图像／编辑／视频页，以及显式保存到“我的提示词”。填入仅替换提示词，保留目标页参数和参考图，不自动生成；静态目录不冒充已发布公共记录、使用次数或逐项实测成绩，原团队与公共模板保持独立。
- 各板块内的提示词选择入口共用同一通用目录，并读取本人、可访问团队及公共模板；按实际接口分页与当前身份刷新。可直接新增个人模板供以后复用，不自动公开或更改共享权限；只填文字与复用完整模板明确区分，填词不自动生成。
- PostgreSQL 保存素材归属、项目、任务、提示词、模型和来源；S3/MinIO 保存文件内容。
- 企业模式的服务端素材按已验证员工归属，媒体读取同样校验；试用完整后端按浏览器访客会话归属，Windows 试用共用固定身份，不承诺员工隔离。旧账号素材不自动公开。
- 历史部门和管理员权限仍在服务端维护，普通创作入口不提供公司管理功能。
- 历史记录保存原图、结果、提示词、模型、参数、积分、人民币成本、状态与失败原因。
- 文生图、图片编辑及共用图片工具的历史可多选、全选和批量删除，确认范围后仅移除本机记录及其本地结果图片，不取消生成或删除服务端任务。创意板块的历史支持批量管理，只选择当前已加载且已结束的记录，原图与服务端任务保留。部分删除失败时保留失败项并选中供重试；不跨账号或板块删除。
- 后台项目素材可切换图片墙与全部素材列表，按关键词、设计师、项目、标签、北京时间日期和新旧顺序筛选；项目行可直达对应素材。图片墙含生成结果及上传图片，按原比例展示，游标加载的数量不冒充全部总数。打开详情才读取完整提示词与元数据，不改变素材的现有权限或共享状态。
- 后台历史详情对本站素材使用鉴权缩略图预览，提供原文件入口；外部或未知类型地址仅显示明确链接，不自动发起第三方媒体请求。不支持或失效的图片保留失败提示，不自动替换原件。
- 管理员可导出 CSV 用于财务、审计和内部复盘。

## 审计与运维

- Nginx 与单机静态服务压缩文本资源，哈希静态文件长期缓存，入口 HTML 不缓存；上传按允许类型及真实字节检查，下载使用安全文件名和 `nosniff`。聊天流式代理的超时与禁止重放设置保留。
- 正式任务采用带心跳的模型租约和按到期时间调度的延迟队列。视频等待期间不占本地执行槽位，但仍计算模型在途并发；有原任务编号时只恢复查询，提交不确定时暂停核查，不自动重复付费。
- 现有异步服务商工作流同样保存上游任务与协议指纹，重启后查询原任务并沿用原期限；配置变更时暂停核查。API 关闭先停止接收请求、排空在途响应，再关闭后台处理及数据库，不提前切断正在保存的数据。
- APIMart 图片参考直接使用原始字节，避免多次 base64 往返；视频预检在短事务外流式读取并探测，重新进入事务时核对模型与素材快照。媒体结果通过有大小限制的临时文件上传对象存储，成功、失败和中断均清理临时文件。API 运行镜像只安装生产依赖并复制运行源码，不打包测试目录。
- 根目录 `bun run dev` 同时启动本地前后端，`bun run check` 检查 lint、构建和测试。镜像发布依赖验证工作流，并分别构建前端与 API；普通代码推送不执行公司服务器部署。

- 登录、改密、账号变更、额度调整、Provider/工作流配置、导出和任务失败均写入审计。
- Provider、模型、板块绑定、部门及内部 AI 配置的业务写入与成功审计在同一事务中提交；审计失败时回滚业务修改。部门列表仅管理员可读，部门管理员仅见所属部门；非法配置编号和已知唯一／关联冲突返回可读错误。共用 Provider 的地址、协议、凭据或启用状态修改需先确认影响范围，取消不发写请求。
- 系统集成页只显示企业微信、加密密钥和对象存储是否就绪，不返回 Secret。
- Docker Compose 提供 PostgreSQL、Redis、MinIO、Worker、初始化和定时备份。
- Nginx 为素材库 `/assets` 与 `/assets/` 提供独立页面回退，直接访问或刷新不会落入同名静态目录；实际 `/assets/*` 文件仍按原路径提供。
- GitHub Actions 验证迁移、身份隔离、备份恢复、40 人并发及任务/账本/素材数量一致性。

## 生成操作便捷性

- 图片页保存原请求与生成参数，刷新后继续查询已有任务；停止本页查询不会取消服务端生成，稍后可继续查询，不会重发生成请求。
- 图片、视频状态查询采用有界等待和短暂失败重试，查询暂停不误报生成失败；视频恢复按记录合并，保留其他任务结果。
- 同账号参考图按内容 SHA-256 复用，减少重复上传；配置刷新失败保留已加载模型，后台标签页暂停刷新，模块初次加载失败可直接重试。
- 后台新增结果不明任务核查入口，可关联已有 APIMart 任务继续查询；Worker 暂时断连后退避恢复，延迟任务保持原排队时间，每位员工的在途任务上限可配置。
- 构建通过类型和体积校验后才替换前端产物，失败时保留上一版；共享任务契约及浏览器回归覆盖上传、工作流、撤销刷新、多标签冲突和批量暂停恢复。

模型与参数记忆沿用现有持久化配置；9 张创意场景封面已无损转换为 WebP，合计约由 18.31 MB 降为 11.25 MB（约 38.6%，不宣称达到教程估计的 70%）。原 PNG 可从 Git 历史恢复。

- 图片、视频工作台在原任务提交成功后展示同模型可运行队列名次，区分排队、延迟调度、生成、暂停及完成。预计剩余时间使用最近 7 天、最多 30 条同模型同操作的成功耗时，至少 3 条样本才估算；调度变化、混合操作、超时或样本不足会显示暂无可靠估算，不保证完成时间。本机试用没有共享 Worker 队列，会明确标注。状态查询失败不影响原任务，也不自动重新提交。
- 提示词库及我的提示词卡片提供“发送到生成页”，只填入草稿；“填入并生成”仍是独立的显式操作。“插入到画布”可选择已有私有画布或新建草稿，加入完整可编辑文字节点，保留模板版本、模型、参数和参考资产编号，支持撤销；不复制参考图片、不覆盖已有节点，也不触发模型生成。插入前重新校验模板权限，账号切换或页面关闭会取消尚未完成的操作；保存失败明确提示，避免重复插入。
- `useGenerationWorkspace` 共用参考图状态、参数与历史浮层、历史选择及删除流程；模型规则、图片／视频参考校验和媒体处理仍独立。删除失败保留确认框和选择，进行中拒绝重复删除；图片、视频页按员工重新建立工作区，不沿用另一账号的界面状态。
