# 功能介绍

复制截图后，在画布区域或左侧“描述图像”输入框按 `Ctrl+V`（macOS 为 `Cmd+V`）即可添加图片节点，同时保留正在输入的描述；直接使用本次粘贴事件中的图片，不依赖额外的剪贴板读取权限。多张图片依次导入并沿用上传图片的原文件保存方式。普通文字在输入框中仍正常粘贴；画布节点的复制粘贴保留，旧节点复制记录不会覆盖新复制的截图或文字。在“描述图像”输入框中，`Enter` 提交生成或生成修改图，`Shift+Enter` 换行；中文输入法选字和长按回车不会额外提交。

画布左侧创建面板在参考图上传、任务提交期间短暂锁定，服务器接收后即可继续提交下一项，无需等待上一项生成完成。每项任务独立保留提交时的提示词、参数和参考图；实际执行并发仍受服务端模型配置限制。

图片、视频及共用生成任务观察的入口，在正式后端通过同一条 SSE 连接接收状态变化提示，再读取原任务快照；相同任务的并发读取合并。仍在观察的活动任务在后台保持推送，连接不可用时复用原观察循环的 2.5 秒 GET 回退，单机演示也保留此回退；普通非活动观察在页面隐藏时暂停，回到页面自动补查。推送和查询都不会重新生成；浏览器冻结、后台节流或断网时不保证三秒内更新。APIMart 图片与视频等待上游期间让出 Worker 执行槽，仍占用对应模型的在途配额，不突破后台并发设置。

图片裁剪支持自由、原图、1:1、4:3、3:4、3:2、2:3、16:9、9:16 比例，拖动到边缘保持比例与图内范围；聚焦裁剪手柄可用方向键微调，Shift 加大步长。取消不改动原图。画布参考图选择取消或重开后清除未确认选择，已添加项禁用并显示标记。本地助手复用原附件数据展示已发送图片，关闭面板再打开不会因预览地址被释放而坏图。

画布对话中的上传图与选中画布图放在同一个参考区，缩略图为 96px，可拖动排序，或选中后点击“前移／后移”（也支持 Alt + 左右方向键）。图片编号、对话读图和实际出图输入沿用该顺序，已发送消息保留当时的图片顺序。对话仅展示简短中文结果、必要确认及失败信息，不展示中间思考、工具明细或完整生成提示词；诊断日志仅管理员入口可见。中文需求在内部整理为完整英文图片指令，必须印在图中的原文保持不变；直接对话改图的结构化目标若格式、英文或约束校验失败，不提交图片任务。只有尚未执行任何写操作的契约模式不匹配，允许一次受限的文字参数纠正并重新校验；其他错误不自动修复。完整指令仍保存在内部生成记录中，不作为聊天正文展示。

画布图片快生、节点生图、局部编辑与角度编辑在提交前保存请求编号，服务器受理后立即保存任务编号。刷新或切换画布后返回，会查询原任务并回填原占位节点；提交响应丢失时按当前账号精确查询请求编号。暂停、查询异常或提交状态未知时保留原任务，“恢复查询”不会重新生成。明确失败或取消后才允许重新提交；停止本地派发不等于撤销已受理任务，正式后端拒绝取消已提交或提交状态未知的任务。历史帧本身不查询任务，旧记录没有任务绑定时无法自动找回。

本机 Mark 图片任务区分查询、下载与结果保存失败，保留脱敏错误码。已取得的结果地址只在服务端保存，恢复优先下载原结果；地址失效时只查询原上游编号，不重新生成。成功恢复后清除暂停错误，重复恢复已成功任务直接返回已有结果。

无线画布保留画布、创意设计、图片、视频、对话、素材和提示词操作界面。是否需要登录由部署开关决定：关闭 OA 不等于关闭独立账号认证；`AUTH_ENABLED=true` 时必须先登录。模型、任务、素材与历史连接服务端，模型凭据和敏感维护接口仍受保护。

## 直接使用与访问边界

仓库环境模板使用 `OA_LOGIN_ENABLED=false`，Docker Compose 的 API 和 Worker 明确关闭 OA，并覆盖旧环境文件中的开启值。Windows 默认启动也免登录，使用固定创作身份；完整后端使用浏览器访客会话。旧员工数据不迁移或公开。以下涉及企业 OA 身份与云同步的说明仅描述保留的可选能力，当前部署不启用；免登录画布保存在浏览器，不承诺员工识别或跨设备恢复。

- 普通用户的创作界面不展示账号、小组额度或管理入口；已认证管理员始终可通过桌面侧栏、手机菜单与画布工具进入后台，不受普通角色门户开关影响。敏感后台仍要求管理员认证，免登录不等于开放管理权限。
- 模型 Key 留在服务器，真实生成仍可能收费；服务仅向受信网络或受控入口开放。
- 企业画布、原图、素材和任务按服务端员工身份隔离；试用模式不能验证企业隔离。旧账号与共用数据不自动迁移或公开，真实 OA 双员工和公司服务器仍待联调验收。

## 独立账号与可选积分

正式后端可设置 `AUTH_ENABLED=true` 使用每人独立账号密码，不依赖公司 OA。管理员从 `/admin/login` 管理，个人从 `/login` 登录并按要求修改初始密码。默认免登录试用不自动升级或迁移旧内容，单机演示不开放后台。

超级管理员可从后台“进入个人工作台”，使用自己的画布、素材、草稿和生成工具；个人内容仍以本人身份保存，不借用设计师账号，也不公开其他员工数据。部门管理员的访问范围不变。

独立账号模式完整配置企业微信后，个人登录页也可扫码，沿用已开通的设计师账号和数据；不自动创建账号，不为管理员开放扫码。企业 OA 模式仍直接复用 OA 身份，不增加扫码步骤。

- 管理员创建、停用、重置账号，支持 CSV 批量导入约 100 位设计师。
- 设置部门、角色、初始积分、每月固定额度，直接设置当月可用余额或临时加减积分；0 是有效值。
- 后台“账号额度”提供持久化的积分计费总开关，默认关闭；关闭不清空余额和价格，重新开启后按设置计费，仅超级管理员可切换。
- 操作价格与模型价格相加后在前端显示预估。
- 提交任务先冻结积分，成功捕获，明确失败按状态结算。正式后端只允许确认尚未提交的任务取消并释放积分；已提交、提交状态未知或结果保存未确认的任务保留原状态与预留积分，不因超时或本地取消而自动退款。已知上游 ID 的任务可继续查询原任务，不重新生成。
- `requestId` 保证幂等，同一任务不会重复扣费。
- 账本记录调整、冻结、结算、释放及操作人。
- 开关对新提交生效，已受理任务继续沿用原价格快照；设置余额和加减分具有服务端幂等及权限检查。

## 服务端提示词优化与配方管理

创意设计九个场景、系列配方、图片工作流的每个步骤，以及服装模板的生成节点，先把表单、用户原文和有序参考图送到服务端扩写，再提交实际图片任务。三个服装模板仍保留原有并行分支，图片工作流仍按步骤串行。生成记录保留用户输入与最终实际发送的提示词。

- 普通图片、画布快生和配置节点默认按原文生成，只有点击“一键优化”才扩写；中文优化结果直接回填并按可见原文发送，不在后台再翻译一版。批量改图的优化默认关闭，开启时仅以第一张代表图扩写一次，整批复用同一最终提示词。
- 反推提示词使用服务端配方，返回英文提示词和中文摘要。独立对话与画布助手的基础行为规则移到服务端，并追加数据库中的服装规则；保留原工具契约、图片来源、连续改图条件和原有统一对话模型配置。
- 扩写失败时默认不进入图片队列；只有超级管理员明确设置基础模板降级才会使用该模板，并标记为“未优化”。网络中断或上游是否收到请求不明时保留原请求待核查，不自动再调用模型。
- 同一账号的相同输入可复用扩写结果；版本、模型配置、字段、文字、参考图内容／分工／顺序、蒙版或语言变化均重新判定。原请求编号不能用于不同扩写输入，另一账号不能读取其记录。页面只展示最终提示词与安全状态，不返回配方原文、原始模型输出或内部版本规则。
- 超级管理员从 `/admin/prompt-recipes` 管理 18 组配方，独立绑定扩写模型、编辑草稿版本、激活或回滚，进行扩写测试和显式出图对比，并查看延迟、Token 及成本。保存草稿不等于激活；实际费用、配置估算和缺失费用分开记录，不把未知费用当作 0，不直接相加不同币种。两组对话补充规则可编辑／回滚，实际行为须通过对应对话入口验证，不混用图片扩写测试。
- 正式后端使用 PostgreSQL；本机演示使用同一 `DEMO_STATE_PATH` 的 SQLite 保存配方和扩写记录，但继续禁止管理员登录与维护 API。首次部署须显式导入并绑定模型，未配置时停止生成，不自动启用或覆盖管理员已有版本。
- 配方导入追加场景保真约束：提取不默认补全缺失内容、工艺图完整入镜、线稿保留可见数量和遮挡、配色不重新设计结构。用户明确指定的印字支持常见引号和结构化文字字段，必须原样出现在最终指令中；有指定印字时将独立的笼统禁字项限定为无关文字。导入生成不可变版本，已有激活版本不会被自动替换，原始文档不改写。

这些约束提高指令与流程的可核查性，不保证模型像素保真、生产可用或每张图都更好。独立蒙版的原始供应商结果与应用无损合成结果分开评价。按项目所有者明确授权，原始方案和完整配方收录在公开源码仓库；网站运行时仍实行管理员权限隔离，但不能宣称仓库中的配方保密。

## Provider、模型与工作流

- 后台“模块开关”集中管理正式能力；“板块 API 配置”分组显示 AI 板块，包括 MJ 多图融合、创意场景、系列配方、画布生图／编辑／蒙版／角度／批量／对话／视频／音频、独立对话及其连续改图。总入口、本地工具和服务不虚构 API 配置；具体入口以当前配置为准。
- AI 板块可单独启停调用和设置费用总额覆盖。图片、视频等板块可独立绑定模型，留空沿用用户选择；独立对话与画布对话共用后台指定的统一文字模型，不提供设计师选型。绑定失效或关闭不会静默换用其他模型。留空费用沿用操作价加模型价，0 是有效总额覆盖；保存仅更新当前板块，编辑共用 API／模型必须进入明确标注的高级页。文字对话按每次成功模型调用计费，工具续答各算一次；总开关关闭时不扣分，明确失败、空回复或截断流返还。非 AI 本地工具不虚构模型扣费。
- 模块入口、API 独立开关和父级开关均生效；服务端提交时重新检查来源、模型能力与绑定，模型配置冲突要求刷新而不自动重发。后台更改会在前台下次配置同步后反映，已有历史、素材和本地备份不删除。
- 超级管理员在“API 配置 → 热门模型”选择最多 5 个已启用的 Mark 出图模型，并使用上移、下移调整展示顺序；保存空列表表示不展示热门模型，不会自动补满。普通接口模型始终保留在画布下方“所有模型”中，不自动加入热门；当前选中模型也不会改变热门顺序。此配置只影响展示，不更换配置 UUID、服务端凭据或板块绑定。本机免登录试用仍不开放敏感后台，正式数据库需执行 `029_model_presentation_settings.sql`。
- 管理 OpenAI Responses／图片、OpenAI Chat Completions、Anthropic Messages、Gemini、火山引擎、RunningHub、ComfyUI、自定义及内部 Provider。管理员在 API 配置中填写 Base URL 和服务端 Key，再为模型选择对应 Provider；Chat Completions 与 Messages 分别使用原生的消息、工具调用与结果回传结构。
- OpenToken 图片与对话模型使用该渠道的服务端 Key，图片可生成或携带原图编辑，文字模型由后台统一配置。旧配置与历史记录保留，前台可用列表以当前启用和绑定状态为准；实际型号、权限与费用由渠道决定，不将历史预置视为实时可用承诺。
- 画布网站 Agent 与独立对话共用后台指定的统一文字模型，设计师输入区不提供 LLM 选型；图片和视频仍按对应板块配置选择。模型凭据只在服务端维护，不在画布重复填写。
- API Key 只在管理员端提交，使用服务端加密密钥保存，设计师接口不返回原文。
- 模型配置包含能力、单次积分、人民币成本、并发限制和启用状态。
- 出图列表保留四个 OpenToken 型号：`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`、`gemini-3.1-flash-image`，并追加已启用的 Mark 独立模型；下拉菜单保留简短用途说明。原有图片、对话、视频、音频配置与历史均不删除。
- 超级管理员通过“APIMart 平台”独立入口配置 API 地址、服务端加密密钥及该渠道的图片、文字和视频模型，包括 GPT2／2.5、Nano、Grok、MJ Blend、GPT-6 Astra、Claude Sonnet 5.5 与 HappyHorse。它们不覆盖其他 API 的原有配置；同名模型使用不同配置 UUID，旧通道与板块绑定保留。逐个模型开关可独立设置，Grok2 新配置默认关闭；图片模型名后显示用途，GPT2 标为“日常最通用模型”。各入口按模型显示真实参数：GPT2.5 画质和分辨率独立，Nano2 Official 支持 0.5K 而 Nano2.1 从 1K 起，Grok 有参考图时不发送 quality，Blend 不显示提示词且只创建一个融合任务；已绑定工具仍服从后台配置。
- Mark 参考图由服务端上传后异步提交，独立蒙版使用 `mask_url`；任务编号持久化后再查询，恢复已知任务只查询原编号，提交结果不明不自动重新收费。HappyHorse 视频按 Mark 独立凭据上传、提交、查询与恢复；不混用旧通道密钥。正式后台配置已在隔离的真实 SQL 引擎和浏览器中验证加密、权限、幂等及重开数据库；演示服务不开放凭据写入。真实图片小样已覆盖各独立图像板块，视觉偏差与目标服务器未验项目另列，不承诺所有出图合格。
- 上述为默认出图列表；管理员为某板块显式绑定其他已启用兼容模型时，该模型会加入可用结果并用于该板块，不会因为默认四模型筛选而丢失绑定。
- 用途说明是选择提示，不代表独占能力或质量保证：直接描述生新图、快速探索设计方向、已有图精修；Gemini 按团队使用偏好标记为“前三个模型不合适时再试”，不是客观性能排名，也不暗示它是服装改款首选。能力参考 [GPT Image 2](https://developers.openai.com/api/docs/models/gpt-image-2)、[Flare / Sunburst 官方介绍](https://openai.com/index/introducing-chatgpt-images-2-5/) 与 [Gemini 图像生成文档](https://ai.google.dev/gemini-api/docs/image-generation)；不承诺原图像素完全不变，也不将官方全部参数视为渠道已支持。
- 管理员保留原始配置名称及展示名称对照，未入选图片配置仍可用原编号识别历史。四个已公开型号在选择器、历史和系统元数据中显示模型 ID；设计师请求及可恢复导出中的模型引用仍使用内部配置 UUID，参数按中性能力类型展示，不返回供应商配置或密钥。其他旧型号继续匿名显示，用户自行输入的提示词不改写。显示名称不参与路由，不改变实际 Provider 调用。
- 服务端验证任务类型与模型能力，音频任务不能误用图片模型。
- RunningHub、ComfyUI 和自定义工作流统一配置提交路径、状态路径、模板变量、成功/失败值与结果路径。

## 常用板块与使用分析

- 常用板块按当前员工的访问次数排序，放在桌面与手机导航靠前位置；仍遵守模块和工具开关，不让快捷入口绕过权限。本地访问计数与待上报事件按员工分区，切换身份不会沿用另一员工的数据。
- 超级管理员在后台独立的“使用分析”页查看人员列表、访问与操作次数、模型调用次数及板块／模型／控件分布；这不是 API 配置内的子页签。点击员工姓名查看个人统计简述、三类图表、已记录请求、完整脱敏提示词、安全模型参数与操作明细。普通用户和部门管理员均不能查看这些人员数据。
- 模型统计以实际任务和文字请求为准，点击模型选项不算调用，恢复旧任务不重复计数。访问、操作、请求、成功与失败分开显示；成功率等仅反映软件记录，不评价员工能力或绩效。
- 可导出单人、跨页多选员工或全员的全部已记录数据，格式为 JSONL，包含覆盖说明和完整结束标记，无隐藏条数上限；支持浏览器下载或选择桌面等保存位置，服务器不会直接写入使用者电脑。断流、取消或缺少结束标记不提示完整导出成功。
- 简短统计摘要不调用模型；深入分析需管理员先预览实际发送内容，再明确选择已配置的文字模型并确认一次调用。默认只发匿名聚合数据，不发姓名、用户 ID、图片或完整提示词；可选最多 8 个、各 280 字的脱敏提示词片段。预览绑定确认内容，重复点击不重复调用，失败不自动付费重试。
- 仅记录本软件业务板块的访问、控件点击、参数选择、提交、下载等操作；不采集密码、密钥、Token、原图字节、操作系统行为或逐键输入。提示词来自实际提交，不保存未发送草稿。历史点击／聊天未采集部分不能补推；离线队列溢出或过期会报告缺口，缺失不等于未使用。
- 人员分析在启用账号身份验证的正式服务中开放，支持企业微信扫码、独立账号及 OA 登录；仅超级管理员可查看人员统计。免登录试用只做本机常用板块排序，不冒用共用身份生成员工统计。启用前未采集的访问、操作和聊天记录不能补回，已有生成任务可参与统计。

## 对话改图与附件

- 独立聊天支持 Markdown、表格和代码块，可复制原文、编辑原消息或重新生成；编辑和重新生成建立新分支，保留原会话及后续消息。模型写入的原始 HTML 不执行，外部图片文本仅显示链接，不自动请求外部图片。
- “停止”结束本页响应或任务观察，不承诺取消已受理的图片生成。停止后的图片任务保留原编号，刷新后不会自动重新开始查询；点击“查询原任务”才恢复观察，不重新付费提交。未核实的图片任务先恢复原任务，不能直接作为新生成重放。
- 聊天图片以本地文件键保存，逐会话记录仅写入变化的会话；打开旧记录时按需转换并保留旧快照。草稿、聊天和素材持有的图片不会被普通本地图片清理误删；这些独立聊天数据仍属于当前账号的浏览器存储，不承诺云端同步。

- 独立“对话改图”与无线画布内对话共用后台指定的文字模型，初始使用 APIMart Claude Sonnet 5.5（`claude-sonnet-5-5`）。管理员在“API 配置 → 板块配置 → 对话改图 → 统一对话模型”修改；设计师端保留全部对话功能和入口，但不显示 LLM 模型名称或选型控件。图片、视频模型选择不受影响。
- 服务端以 `gpt-chat.modelConfigId` 为唯一对话模型来源，不接受浏览器、旧会话或旧节点覆盖；`canvas-chat` 的模型继承它，开关和费用仍单独生效。未指定模型，或模型、API 服务不可用时明确停止，不自动换用其他模型。管理员可选择已启用且服务可用的文字模型，历史记录不删除。
- APIMart Sonnet 按 [Claude Messages 文档](https://docs.apib.ai/cn/api-reference/texts/general/claude-messages) 接入 `/v1/messages`，GPT-6 Astra 继续使用 Responses；通用文档的协议核对和本地模拟验证不等于指定模型的真实可用性或付费验收。
- 对话出图仅提供支持文字提示词的图片模型；无提示词的多图融合模型保留在独立融合／画布流程。旧会话误选融合模型时回落到兼容候选；后台若明确绑定了不兼容模型，则停止出图并保留纯讨论，不跨供应商绕过绑定。
- Claude Messages 的 `anthropic-version` 使用 [Anthropic 官方版本](https://platform.claude.com/docs/en/api/versioning) `2023-06-01`。画布助手在完整回复落盘后才结束发送状态；保存失败保留可见回复并提示复制重要内容，避免把“已返回”误当作“已保存”。
- 正式对话的传输失败区分“业务请求尚未发送”和“请求可能已发出、结果待核查”，不自动重发；响应正文中途断开也保留安全诊断，不误归类为普通 JSON 格式错误。上游已返回部分内容时保留可见内容并提示核查，不把原始凭据或代理地址暴露给客户端。
- 对话改图支持图片、文本与代码、PDF、Word（DOCX）、Excel（XLSX/XLS）。每次最多 5 个附件，单文件不超过 5 MiB，总计不超过 8 MiB；图片保留原始字节，仅临时读图预览会缩小。
- PDF、Word、Excel 先在浏览器提取文字，再随问题交给模型；不等同于原始文件完整直传，文档中的嵌入图片、版式和扫描件 OCR 不在当前能力内。普通文本最多保留 80000 字符，Excel 按工作表采样并限制为 8000 字符，截断会标记。
- 文字、文件正文和图片在同一条对话中理解；新图片可作为修改对象或辅助参考，不直接清掉历史图片。历史文字请求最多携带 24 条消息、48000 字符，另提供最多 40 项图片目录与最多 28000 字符的当前图片执行条件；每次预览最多 5 张、8 MiB。截断会标记，浏览器内的完整历史不会因请求窗口缩短而删除。
- 独立对话改图页面的聊天记录与已发送附件内容通过 localforage 保存在当前浏览器的 IndexedDB，企业模式按员工分区，刷新后可继续问答但不代表云同步；画布内聊天随整张画布保存，企业模式参与云同步。保存失败会明确提示，发送前保存失败时保留草稿和附件；旧版仅保存的文件名无法还原已经丢失的附件内容。
- 画布网站 Agent 的附件入口目前仅支持图片；PDF、Word、Excel 的问答请使用对话改图页面。

## 连续图片创作

- 对话改图只有一个发送入口，不再区分聊天、创作或 Agent 模式，也无需选择理解模型、编辑起点或点击“继续编辑”。直接上传图片或要求文件并说修改需求，后续只发文字即可继续；普通问答、资料分析、提示词整理、生成和改图由后台指定的同一对话模型判断。
- 这是应用组合模式：对话模型规划，图像模型通过已有任务、服务端会话和素材链路执行；内部积分由后台总开关与对应板块价格决定，对话续答与图片工具分别计费。它不是 Responses 原生 `image_generation` 工具。当前 OpenToken 实际接口拒绝该原生工具，不能把 OpenAI 官方支持直接等同于渠道支持。
- 上传图与生成版本的稳定身份、真实来源和上次结果在后台保存；模型按本轮语义区分修改对象和参考图，可以自然表达“改刚上传的这张”“回到第一张”“只参考这个颜色”。明确的续改要求直接执行，只有确实无法判断对象或缺少必要条件时在对话里追问，不要求操作选图控件。需要查看未预览历史图时可只读补看一次，再决定回复或执行，不循环生成。
- 独立对话将本轮修改、仍有效的保留条件和参考图分工共同编入实际图片请求，不再只保存保留项而漏传给出图模型。参考图按稳定图片身份映射到本次传图编号；排除图、歧义编号、无效约束及超过 20000 字符的完整指令在提交前阻断，不静默截断或换图。明确撤销的条件不再执行，不把其他历史分支或生成成功自动视为用户认可。
- 原始工具 JSON 在转换为对象前拒绝同一对象内的重复字段，防止只留下最后一项而静默丢失约束；不会自动合并坏参数或重试付费调用。已经由上游转换成对象并丢失的信息，客户端无法追溯恢复。
- 实付小样已验证独立对话从三张素材中只传指定两张并正确重排编号，以及以上一轮结果继续修改；画布对话已验证回最初原图重做时保留累计修改目标，以及再用最新结果替换旧颜色要求。实际输入文件、最终提示词与成图分别核对，刷新重开保留结果和最终回复；不能用请求成功替代视觉验收，当前小样仍有细微纹理与明暗重绘。
- 图片模型沿用会话或现有配置，按生成/编辑能力自动选择，不要求用户每轮配置两个模型。纯讨论不提交图片任务；仅上传而没有文字要求时先读取内容，不直接执行文件正文中的指令。每轮最多一个图片任务；没有图片服务仍可正常问答，只有实际需要出图时提示服务未配置。
- 输入框旁的“清晰度”按图片服务支持的画质或分辨率档位显示，选择随会话保存并应用到生成、改图请求，不改动其他页面的全局参数；高画质不等于更高像素尺寸。参考预览受限并行处理，流式工具开始返回时显示准备阶段，图片任务仍需等待上游服务完成。
- 所有新上传保留原始文件字节，实际编辑使用原图；历史上已压缩的旧附件无法还原原字节。完全重新创作使用 `generate`，不传旧图或建立虚假父链；依赖参考图的创作使用 `edit`。图片来源与保留项是执行记录，不代表视觉质量或未修改区域逐像素一致。
- 会话保存模型、图片结果、完整执行提示词及图片来源关系；保留各版，不覆盖旧图。图片的“放入画布”会创建或复用该会话对应的画布，保留原始比例；企业模式按员工同步画布，试用模式本地保存。重复点击或保存失败后重试不会新增相同节点。
- 生成前保存失败保留草稿；规划或上传期间离开页面、切换账户，会停止尚未提交的任务准备；已提交的任务继续由服务器执行，不会因为页面退出重新提交。
- 出图过程中刷新，依据已保存的请求或任务 ID 只查询原任务，成功后将图片及来源关系恢复到原会话、原消息，并以新结果继续编辑。状态未知、暂停或找不到任务时保留待核查提示，可查询原任务，不自动重新生成；同会话在查询期间禁止重复提交，可切换到其他会话。

## 图片、视频与音频

- 图片与视频创作页支持 `Ctrl/Cmd+Enter` 提交、`Escape` 收起设置；输入法组合输入、重复按键、运行中或校验失败时不重复提交。模型与参数沿用现有持久设置。

- 创意设计另有三个正式工作台：`/creative/pattern-placement` 图案定位、`/creative/pattern-repeat` 花型循环，以及 `/creative/series-recipe` 系列配方。定位和循环执行本地二维编辑，不调用模型、不承诺 AI 面料融合；系列配方冻结参考、配色和约束后通过真实图片编辑任务生成。三个板块各有后台开关，系列配方另有独立 API／模型配置。工程按当前身份保存在浏览器，可导出后跨设备导入，不代表云端保存；原 `labs/` 模拟页不参与正式运行。
- 图案定位和花型循环支持多个本地工程、修改后自动保存及离开时未保存提醒，可从素材库选图，并将导出结果另存为个人素材。实验页复用正式编辑实现，系列配方仍保持独立。原工程与原文件保留，不承诺跨设备同步。
- “创意设计”是独立板块，提供新款、改款、图案三组九个场景：以文生款、款生线稿、局部改款、服装配色、背面设计、花型提取、图案配色、辅料设计和图案工艺。卡片使用独立制作的输入／输出示意封面，每张进入专用 `/creative/:presetId` 页面；原有文生图和图片编辑工作台不加入这些控件。
- 各场景使用专用输入：款式描述与品类／廓形，线稿风格与细节，局部修改部位与保留项，智能／HEX 色板／参考图配色，背面结构与图案处理，花型提取范围与背景，工艺与承载面料，以及辅料图＋图案图的双图角色。字段直接组成可查看的设计指令，不再要求先套用通用提示词框；仅点击生成后提交任务。右侧显示该功能示例、当前结果和最近任务。
- 场景草稿与已结束生成记录按当前账号和场景分开，使用本机 IndexedDB 保存表单、角色图片、出图参数与结果，刷新可恢复草稿；不存 Provider 凭据，不改变原工作台的模型设置。底层复用现有图片生成／编辑、模型和计费链路；每次固定一个单图任务，已有多结果历史保留。此场景工作台尚不提供生成中刷新后的任务恢复，请保留页面直到结果保存完成。
- 创意场景历史按摘要分页，仅在选中时读取完整记录与原图；旧历史保留。结果可加入素材、插入画布或用作参考。单项重试仅针对服务端确认失败且原始输入校验通过的任务，使用原模型与参数重新提交一次；查询暂停、状态未知和本地合成失败不自动重试。不同场景不再共用图片工作台的提交锁。
- 局部改款可涂选／擦除修改区域，选区绑定原图并随草稿、任务记录保存；更换或移除原图会清除旧选区。生成时向模型提供原图与蓝色选区示意，再将返回图按选区合入原图，未涂选的像素保留原图。保存选区时匹配输出比例；比例冲突在提交前拦截，模型实际返回比例不一致或合成失败时保留未合成图供下载，不自动重发。它不是模型原生蒙版，选区内的主体对齐、结构、接缝和光影仍需核对。
- 图案配色另有本地精确换色：从原图取色或输入 HEX，设置最多六组原色→目标色及 RGB 容差，对照预览后以原尺寸 PNG 保存。映射不连锁，未匹配颜色及透明度保留；无需模型或生成积分，记录明确标记为本地处理。它适合平面花型，不自动保留照片明暗，也不保证印染／实物色差。
- 服装配色的“指定颜色”可从标准色库选择：默认浏览 PANTONE TCX，可筛选 73 个色库／分组、搜索 81,583 个色号，或从已上传款式图取色，按 CIEDE2000 查找相近色。数据分块按需读取，进入画布不加载色库全集。应用色卡只填写对应目标色，不调用模型；生成指令同时写入库名、色号与 HEX，并要求保留面料纹理、褶皱、光影、版型、人物及背景。
- 已以单件衬衫样图验证 Sunburst 的真实生成、原始 PNG 保存和历史结果恢复：目标红色覆盖面料，蓝色纽扣及主要结构视觉保留。此验收仅证明该样本的概念配色可用，不等于生产色准或非改色区域逐像素不变。
- 所选色号的 ID、库名、HEX、来源链接与数据版本随账号和场景草稿、生成输入及历史保存；手动改 HEX 会清除旧色号关联，删除颜色会同步调整记录。数据为公开网站快照，覆盖已枚举的公开入口，不代表服务器全部数据或实物测量值。原站 Munsell 目录声明比公开记录多 100 条，969 个色号存在来源色值差异，按结构化接口取主值并保留冲突与来源档案。屏幕匹配与 AI 输出均为近似视觉参考，生产用色仍须核对实物色卡。
- 款生线稿可将上传的线稿或 AI 结果在本地描摹成真正含路径的 SVG，不嵌入位图；提供黑白阈值、小路径过滤、平滑参数与预览，最长边按 2048 像素处理，在独立 Worker 中执行。输出是黑白轮廓路径，不是中心线、纸样、尺寸技术稿或可直接生产的文件。
- 必填图片、款式要求和 HEX 格式在提交前校验。AI 场景用于概念探索：背面设计不是对不可见结构的事实还原，花型提取不保证完整复原或无缝循环，AI 配色不保证精确色号，工艺和辅料效果不等于生产文件。封面为 AI 功能示意，不是当前模型实测结果。
- 文生图、参考图编辑、局部编辑、细节增强、角度控制和无缝拼接。
- 无缝拼接支持单图与 2×2 循环预览；读取历史结果不重复写入本地图像库。剪贴板失败会区分权限、无图片与格式不可用，不静默清空已有参考。
- 文生图、细节增强、图片编辑、角度控制的记录和结果按账号与工具分开；未标记来源的历史通过原任务确认归属，无法确认的留在折叠的“未分类记录”，不混入默认结果，不删除原记录。切换工具时，后台完成的任务只更新其来源板块。
- 图片和视频工作台点击记录或结果会回填该结果的原提示词；创意场景在左侧展开所选结果的原始设计指令，不改变当前表单。查看结果不更换模型与参考素材，不提交生成；需要恢复完整输入时使用“恢复为草稿继续改”。
- 视频工作台和画布按型号提供首帧、尾帧、首尾帧、多素材参考、编辑或续写，支持对应型号允许的图片/视频/音频输入及有序引用。
- 视频提交前检查素材所有权与模式限制，服务端读取媒体实际尺寸、时长和帧率；无效素材不会直接触发付费生成。音视频参考需要渠道可访问的 HTTPS 素材入口。
- 视频任务受理后即可继续提交下一项，各项独立保留结果与恢复入口；提交响应丢失时按原请求编号查询，不再次生成。已下架的选择明确提示，不静默改用其他模型；生成结果加入个人素材时复用已有文件，不重复上传。渠道拒绝会保留有长度限制且移除凭据的错误详情，不能从历史上仅有状态码的旧记录补回原因。
- 画布音频节点可提交服务端音频任务并保存结果。
- 正式后端的图片、视频、音频和工作流任务进入 Redis 队列，由 Worker 解密 Provider 凭据后调用上游；Windows 本机试用服务直接执行任务，不依赖该队列。
- 设计师浏览器不保存外部模型 API Key，也不直接调用带密钥的上游接口。

## 无限画布与批量改图

- 单张图片下载可选原文件、PNG 或 JPG；PNG 保留透明，JPG 将透明区域填为白色，转换保持原始像素尺寸。导出图片集可将选中或全部图片逐张转换并打包 ZIP，原文件 ZIP 与 PDF 仍保留；这不是将整张画布合成为一张图片，不改动节点或原件。

- 画布顶部、弹窗、节点／连线图层与快捷键、历史、持久化、剪贴板和生成运行状态分别维护。每个编辑器拥有独立的 Zustand 图状态，节点按 ID 订阅自身与流式文本；悬停和逐字流式更新不再使整个编辑器订阅这些高频状态。
- 图片预览按缩放档位切换，服务端素材使用 256／1024 WebP 缩略图，放大及原图操作仍使用原件。云端画布列表读取预先保存的摘要，保存只返回版本确认，保留原有冲突副本、删除墓碑及离线恢复语义。

- 选中修改后图片，可直接在图片内拖分割线或在下方拖“原图—修改后”滑块，无需打开窗口；支持键盘调节，拖动不移动节点、不改图片文件。新生成与本地编辑保留当时的来源快照，唯一可靠来源默认作为“本次修改前”的直接上版。选图入口常显当前原图缩略图与名称，打开后用大缩略图分组显示本次输入来源和其他画布图片，支持搜索与键盘选择，弹层不会随画布缩放变小。多参考图、旧参考记录或来源缺失时须手动确认，不按连线、同名或版本号猜原图；手选后进入高级对比仍保留当前选择。尺寸不同等比查看并提示，非像素对齐。
- 图片下方“更多”及图片操作菜单保留高级对比和“整套服装画布模板”。高级对比支持滑块、并排、透明叠加和差异图，以及适应、1×、2×、4×滚动检查；倍率不改变 PNG 导出尺寸。差异图在同尺寸且未超限时逐点比较浏览器解码后的像素，透明区域内隐藏颜色不计作可见差异；不同尺寸按比例居中，超过 400 万像素或单边 4096 会降采样并明确提示，不能当作原像素一致性检验。不修改原图、不调用模型、不自动配准，也不代表自动质量检测；浏览器仍需解码原图。
- 服装模板提供整套款式开发、花型与工艺开发、系列配色提案：以所选原图为共同参考，创建 3 个有提示词和连线的可编辑生成配置。添加模板不自动生成；每个配置分别点击“生成”才调用模型，三个分支不自动串联，技术线稿和工艺效果仍需业务核验。
- 图片工作流由画布上的真实连线定义：原图连接第一个生图配置的左侧，从配置右侧拖线到下一个生图配置左侧，或拖到空白处新建配置节点。各节点独立填写提示词、选择模型与尺寸，直接点击节点上的“运行工作流”即可按依赖执行，无需先分组或进入弹窗。支持串联和一个上游连接多个下游的分支；每个节点只接受一个上游图片，分支各自使用其父节点的结果。循环、多上游及缺少原图会在提交前阻断。
- 图片“更多工具 → 图片工作流”只是快捷搭建入口，可预填“抠成白底 → 改成紫色 → 模特上身”并生成 1–10 个横向连接的配置节点；添加不调用模型。最终执行顺序以连线为准，不以节点位置、组内列表或创建顺序为准。原图和中间结果保留，运行记录可从组标题查看。
- 工作流失败即停，不自动重试；“继续工作流”在连线和参数未改变时跳过已完成步骤，优先查询未决的原任务，结果不明时不盲目重提。完成后再次运行，或修改连线与参数后运行，会创建新的一轮。流程随画布保存；刷新、离开或关闭页面不会自动执行后续步骤，重新打开须手动继续。每步单独计费，停止不保证撤销已提交的服务端任务。当前是图片节点工作流，不兼容 ComfyUI 的插件／工作流文件，不支持多输入合并、多结果自动选图或后台无人值守。
- 模板窗口可编辑流程名称、三个步骤名称及提示词，保存为“我的模板”；支持更新原模板、另存一份，以及关闭／刷新后再次复用。个人模板按当前员工保存在本浏览器 IndexedDB，暂不跨设备同步，清除网站数据会丢失；保存失败保留编辑内容，不覆盖原记录。保存模板不添加节点、不调用模型；应用时绑定本次选中的参考图，更新模板不改变已添加的画布流程，内置模板保持不变。
- 底部“自动整理排版”可网格整理、顶部／左侧对齐、横向／纵向等距排列；有选区时处理选中内容，无选区时处理整张画布。款式组和批量图保持整体移动、保留组内布局；操作可撤销并跟随画布保存。
- 多选至少两个节点，点击底部“创建款式组”、右键同名菜单，或使用 `Ctrl / Cmd + G` 创建款式组。组标题支持重命名、拖动整体移动、折叠／展开与取消分组；分组不是图片合并，折叠只隐藏成员及相关连线，取消分组保留全部内容。批量图片作为整体归组，分组和成员移动支持撤销／重做，完整复制组内成员时保留分组并生成新 ID。
- 款式组随整张画布保存、企业云同步和画布 ZIP 导入导出，包含名称、成员关系与折叠状态。折叠组内未选中内容不作为助手的可见画面自动读取；明确选择的素材仍可作为上下文。
- 图片节点根据实际显示尺寸、缩放和屏幕像素密度选用 256／512／1024 像素预览，接近原始尺寸时切回原图。预览缓存按员工隔离，最多保留 128 份，后台单队列生成；格式不支持或缓存失败时回退原图。此优化只影响画布显示，不改写图片内容、编辑源、导出文件或云端原图，也不承诺所有设备或首次解码均更快。
- 画布包含节点位置与尺寸、连线、文字和编辑内容、图片／视频／音频及参考图、画布内聊天、最多 50 步撤销／重做历史和视口。企业模式先写员工分区的 localforage / IndexedDB 缓存，再上传原始媒体并同步服务器文档；试用模式只保存本地画布。保存不缩放或重新编码原图，手动编辑结果按现有字节保存。
- 企业页面区分本地保存与云端同步状态；失败保留待同步内容，不伪称成功。确认已同步后，同一员工可从公司 OA 重开或换设备恢复；不同设备写入使用版本校验并保留冲突副本，删除墓碑防止旧设备复活，不是实时协作或无限历史。
- 试用画布、未同步内容、独立聊天和创意草稿换环境前需导出或另存，不清理网站数据、不用无痕会话保存重要作品。分享链接不授予员工访问权；旧账号与共用数据不自动迁移、删除或公开。目标公司环境的恢复和隔离仍需实测。
- 画布本地自动保存尚未完成时，刷新或关闭页面会立即尝试写入并请求浏览器显示离开确认；取消离开可继续等待保存。强制离开、崩溃或断电仍可能丢失未落盘改动，重要内容应导出备份。
- 图片平时不显示常驻边框、阴影和圆角裁切；悬停显示细边框，选中才出现缩放控制点和快捷工具，点击空白处隐藏。默认快捷工具为“编辑图片／AI 编辑／下载”，局部重绘等次要操作在“更多”中，已自定义的快捷工具仍保留。连线点在选中并悬停或连线过程中显示，常规流程节点的连线入口不变。
- 画布工作区使用中性灰白背景、点阵网格、左侧创建面板、左上项目菜单、右上工作区信息和底部浮动工具栏，深色模式沿用同一套灰阶主题。模型入口放大，模型面板按品牌图标、用途及实际支持参数展示，打开时展开并定位当前模型。比例、画质菜单从按钮下方展开，短窗口中创建区让出下方空间；“更多设置”打开宽大窗口，使用分区卡片与可直接点选的参数选项。菜单和窗口均有明确的返回入口，关闭不会清空提示词、参考图或已设置参数。每个图片任务仍固定生成一张，不虚构价格、耗时或未接入模型。
- 打开已有内容的画布时，创建面板默认收成紧凑入口；桌面空画布仍展开。面板可手动折叠，点击或框选图片不会强行展开，仍自动更新参考图。“AI 编辑”可带参考图重新展开创建面板。取消选中不清空参考图草稿；背景和图片信息集中在底部“更多工具”，对比、模板和排版集中在“设计工具”。左上菜单和底部“全部工具”保留现有板块，可搜索进入，仍遵守原有模块与权限开关。窄屏从“更多工具 → 画布生图”展开创建区。
- 桌面创建／窄栏对话面板默认宽 480 像素，字体与按钮同步放大。“大小”入口提供宽度滑块、紧凑／舒适／宽敞预设，创建区还可调输入区高度；也可拖动右边缘调宽，标题区域同步对齐。两种面板分别记住本机宽度，双击边缘或聚焦后按 `Home` 恢复默认，左右方向键微调。创建区内的长内容独立滚动，底部参数和生成按钮保留可见。
- 画布左上角菜单提供“导出图片集 / PDF”。可导出全部图片或当前选择，勾选后按上下箭头调整顺序，并填写图片集名称；支持一个多页 PDF、每张一个 PDF（ZIP）或原图 ZIP。批次封面自动展开为实际子图，不重复导出封面。每批最多 200 张、原图合计 256 MB；PDF 单图最多 2000 万像素，每张图独占一页，按原图比例设置页面，不拉伸或裁切。PNG/JPEG 直接嵌入，其他可读取格式转为静态 PNG；原图 ZIP 不改动文件内容，某张读取失败时整次停止，不交付缺页文件。
- 图片上传默认沿用文件名，可从节点右键菜单“重命名”修改名称；显示图片信息时可见名称与版本。初始版本为 v1，手动编辑或基于参考图生成的结果沿用来源名称并递增版本，多参考图以第一张为准；重命名本身不增加版本。图片下载及图片集内文件使用“名称_v版本.实际格式”，ZIP 中额外加顺序编号避免同名覆盖，PNG 编辑结果不会因来源为 JPG 而丢失透明通道。
- 新图片拖入、文件选择、粘贴以及画布参考图和批量上传均限制单张不超过 20 MB（20 × 1024 × 1024 字节）；超限在保存或上传前拒绝并提示，不自动压缩，不删除已有图片，也不影响生成结果归档。图片还须成功读取真实尺寸；空文件、损坏文件、读取超时或下载失败不会保存成占位图片，也不使用虚构尺寸继续编辑。
- “编辑图片”新增自定义宽高，支持 728×90 等正整数像素尺寸。最长边不超过 8192 像素、总像素不超过 2500 万；默认等比缩放并透明留边，也可选等比居中裁剪或明确拉伸。尺寸变化支持撤销／重做，保留透明通道；这是本地图片编辑，不调用 AI，也不改变模型本身支持的生成尺寸范围。
- 生图工作台的历史结果卡和“我的素材”图片详情提供“编辑原图”，可恢复本地保存的原始图片直接修改。保存会另存为当前用户的新素材版本，原生成记录、原素材与原图均保留；新版可重新插入画布继续编辑，名称和版本信息跟随传递。此处的版本用于同源结果标识，不是覆盖式历史回滚系统。
- 在线画布助手默认在发送消息时读取当前可见、选中或正在预览的素材，不必逐一附加。优先预览与选中内容，排除画面外、折叠批次和被面板完全遮挡的未选中节点；移动画布后，下一条消息使用新的视口上下文。输入框上方可关闭自动读取，手动参考和画布结构仍保留。
- 画布助手多轮对话同时携带最近 24 条消息（48000 字符）及对应的用户参考图、当轮自动读取的图片快照和助手生成结果，标清消息归属以便理解原图、各版结果与反馈。历史图片引用固定素材，不随当前节点变化；分析图片与实际改图底图区分，历史图片不会全部混入生成输入。理解用预览图最长边 1280 像素，不改动原图；历史、本轮参考与自动画布图像共用最多 20 张、6 MiB 内联图片字符的请求预算，优先本轮手动参考、本任务原图/最新结果及较近历史。超限/失效图片与较早消息省略数量在消息状态及模型输入中披露；旧会话中未保存的自动画布图片不能追溯恢复。
- 连续改图先理解要改与保留的部分，再整理完整编辑指令并调用已配置的图像模型。用户针对结果提出具体不满意点时，分析结果但用本任务第一轮原图重做；“再好看一点”等继续美化请求使用最新结果；明确指定底图优先，新任务重新建立原图关联。模型通过 `editIntent` 判断语义，代码落实真实底图选择；原图、初始要求及最近编辑要求随成功结果保存，关键原图证据不受 24 条消息窗口截断（仍受总图片预算限制）。缺少原图或多张最新结果无法确定目标时不提交错误底图；生成失败不替换上一份成功结果。图像工具沿用用户在创作预设选择的模型，规划模型不能通过工具参数偷偷换模型。此规则适用于对话直接改图；用户显式操作已有生成节点时，仍按节点指定的模型和参考连接执行。
- 画布连续改图保存结构化的当前修改目标、保留项和禁止项；后续默认继承，替换或撤销须明确指向旧条件。每项保留用户要求原文作为来源，最终英文指令由当前有效目标编译，回到原图重做也不会因只传本轮差量而丢失前轮目标。提交前校验参考图身份、明确数量／否定／图中文字及完整长度；不能可靠映射或校验失败时不调用图片模型。此校验不是任意语义的完备证明，也不保证生成图逐像素不变。
- “再来一张／再跑一张”按原图与已保存的完整目标重做；旧记录缺少结构化目标时，只允许用同一任务的真实用户原文完整重建，不借用其他任务条件。模式纠正最多一次且固定原参考图、图片模型、张数和生成参数，纠正后仍完整校验来源；已提交图片、已执行其他写操作或纠正再次失败时停止，不重复生成。
- 视觉对照要求区分整体缩放/移位与内部结构变化，并以当前图片复核历史助手结论；无依据的旧判断应撤回，已修复问题不再列为现存缺陷。外轮廓、部件数量和中心区域分开核对，不以局部遮挡跳过清晰可见部分；对象尺寸不同时，没有等尺度对照或可靠测量不得确认内部比例改变。无法看清的细节需明确保留不确定性，不把猜测自动写进改图提示词。该约束用于减少过度推断，不替代像素测量或人工工艺核对。
- 自动上下文每轮最多包含 24 个节点、6 张图片、2 个视频及 12000 字符文本；单节点文本最多 3000 字符。图片与视频抽样图最长边 1280 像素，仅供理解，不改动原素材。视频提供开头、中间、结尾的带时间抽样帧，不代表完整动作分析，音轨不自动收听或转写。超限与读取失败在模型上下文中明确标注；自动读取不触发生成或编辑。
- 空白处右键“生成”打开创建面板并记住点击时的画布坐标，下一批图片从该位置向右、向下排列；生成完成后左上角位置不漂移。定位只消费一次，参数校验失败不会丢失定位，可点击“取消定位”恢复原有自动排版。点击菜单本身不提交付费任务。
- 空白处右键“上传图片”直接打开本机文件选择，将所选图片放在右键位置；保留原图与原有多图上传规则，不触发模型生成。菜单支持键盘选择、Escape 关闭和返回焦点。
- 节点右键不启动拖动、缩放或连线；右键已选节点保留当前多选，未选节点则仅选中该节点。多选菜单明确显示复制／删除的项数，复制保留内部连线、完整款式组及批次关系。

- IndexedDB 画布按项目独立保存，只读取、合并和写入发生变化的项目及必要的冲突副本，避免多项目时每次重写整个项目库。索引与文档在同一事务中提交；图像字节、节点、连线与聊天不做有损压缩。此优化主要改善多项目保存，不承诺单项目操作或所有设备均更快。
- 画布分片采用新本地存储格式，不自动迁移旧格式。更新前请在旧版导出需要保留的画布，更新后通过“导入画布”继续使用；旧存储不会被本次更新删除。不要将新列表为空误认为旧数据已被清空，回到旧版仍可导出。原图存储与“我的素材”不因项目分片而改写。
- 同一浏览器多个窗口保存同一画布时，以各自编辑前状态为基线合并节点、连线、会话及独立字段修改；真正冲突时保留“保存冲突副本”，不静默覆盖另一窗口的版本。IndexedDB 在单一原子事务中读取、合并和写入，局域网 HTTP 不依赖 Web Locks；失败保留待保存改动。该本地合并机制不是实时协同编辑，另一窗口的合并内容需刷新或重新打开后查看。
- 多项目画布、节点拖拽缩放、连线、撤销重做、导入导出和小地图。
- 图片、文本、视频、音频和生成配置节点可互相连接。
- 生图配置卡内直接编辑提示词、上传和管理参考图，并选择模型及其支持的参数，无需另开提示词编辑面板；输入、上传或调整参数本身不调用模型。普通缩放／平移保留卡内编辑内容，远景概要模式仍按原有缩放规则生效。Blend 融合模式不显示提示词输入。
- 未显式连接右侧待处理目标时，普通生图配置左侧接入多张图片默认“逐图执行 · N 个任务”：每张输入图独立生成一张，共用本轮提示词、模型、参数及手动添加的公共参考，不混入其他输入图。每个任务主图均为图片1，公共参考从图片2起编号；新结果放在配置与原图右侧并避开已有节点。可切换为“合并参考 · 1 个任务”，将多张图共同用于一个结果；Blend 仍按多图合并执行，不自动拆成逐图任务。
- 从合并参考切换为逐图执行时，单一任务图的固定 `@` 引用改为“图片1”，公共参考引用保留；若提示词同时指定多张不同任务图或引用了已移除图片，则保留合并模式并提示调整。旧逐图配置仍有固定任务图引用时禁止直接执行，避免任务主图与指令对应错误；切换时保留尚未完成延迟保存的输入。
- 配置节点左侧接入公共素材，右侧“共享配置输出”可连到多个待处理节点；点击“执行 N 个任务”逐项使用同一套提示词、模型和参数，每项只带自己的输入与公共素材，不混入其他任务的图片。图片模式当前主图为图片1，公共参考自动顺延；原图和已有内容保留，结果另建节点，空输出槽可直接填写结果。
- 共享配置支持画布现有图片、文字、视频和文字转语音模式，仍遵循各模型的输入类型与参考数量限制；这不代表蒙版、无缝拼接等专用模块已通用接入。一个目标只接一套共享配置；目标面板显示继承内容，可打开公共配置或只执行当前任务。连接或改参数本身不调用模型，执行时冻结本轮参数；停止后不继续派发后续项。图片及新提交的音视频结果保存请求身份，未决时先查询原任务，不自动重复付费；文字流中断不自动续传。
- 图片工具栏的“编辑图片”打开手动编辑面板，支持框选裁剪、画笔、矩形、箭头、文字、马赛克、旋转及面板内撤销/重做。确定后以 PNG 保存回原画布节点，保留连线；取消不改变图片。保存后可用画布撤销恢复原图，再次点击图片可使用独立的“AI 编辑”，手动编辑不会自动调用模型。
- 手动编辑先保存到本机浏览器，企业模式确认后的节点结果随画布云同步，试用模式仅本地保存。面板按需加载，保留图片原始分辨率（最长边不超过 8192 像素、总像素不超过 2500 万），超限明确提示。马赛克仅为视觉遮挡，敏感信息应使用不透明涂画完全覆盖。
- 当前编辑会话内绘制的矩形可在矩形工具下直接拖动，支持撤销/重做；按 Shift 可在已有矩形内新建矩形。保存后标注合并为 PNG，不保留跨会话可编辑图层。
- OpenToken GPT Image 2／2.5 提供合规自定义像素、2K／4K 档预设与自适应，2.5 另支持 xhigh／max；画质与分辨率分开。新建配置默认 APIMart GPT2，保留有效的已保存模型和参数。高级面板按当前模型提供背景、输出格式与压缩质量，以及其他已接入渠道的专属参数；不启用停用渠道。大尺寸和高画质可能增加费用与耗时，超出渠道限制明确报错。
- 单张透明图通过 OpenAI 兼容图片编辑入口提交时，在未显式选择背景或格式的情况下自动附带 `background=transparent`、`output_format=png`；只读取透明度，不改变输入文件，模型返回文件原样保存。不覆盖多图合成、蒙版编辑及其他渠道，也不保证未指定区域逐像素不变。
- 花型提取／图案配色的结构化单次请求另由服务端按已授权主图的真实像素解析背景，多参考时仅取第一张主图，不取配色辅助图。白底或不透明原背景覆盖残留透明设置；保留透明原背景时，仅使用已接入原生背景参数的模型，并拒绝 JPEG 冲突或不支持的渠道。此检查位于提示词优化后、生图提交前；不承诺所有付费调用前阻断，也不扩展为通用批量透明推断。
- 请求透明背景时，结果校验解码后的实际 alpha；全部像素不透明则保留渠道原件并暂停任务，不自动抠图、套用原图 alpha 或重新生成。存在透明像素只证明 alpha 存在，不证明主体不透明、没有光晕或边缘符合要求。本轮 Flare／Sunburst 已取得透明结果，但光晕仍未通过视觉验收。
- 画布原生蒙版编辑将 PNG 蒙版独立提交到 mask 字段，不再充当普通参考图。服务端在提交前验证第一张原图与蒙版为单帧、8 位、尺寸一致、单边不超过 8192 且不超过 16777216 像素，蒙版须带透明通道且小于 4 MiB。不支持的模型直接报错。节点改图固定当前原图为图片1，附加图编号与托盘、@提及、画布标签和提交顺序一致。
- 蒙版绘制预览最长边为 1200 像素，笔刷直径按当前显示像素计算；实际选区及提交 PNG 始终保持原图尺寸。涂抹中按动画帧更新预览，笔画结束只扫描小预览，提交时才读取原尺寸蒙版。已有涂抹或修改要求时，关闭、Esc 和点击遮罩均需确认；继续编辑保留内容，窄屏可滚动至提交按钮。
- 模型返回后先保留渠道原件，再将生成结果按独立蒙版合成回第一张原图：蒙版不透明像素保留原图 RGBA，透明像素使用生成结果，半透明像素按权重混合。主图保存为无损 PNG；结果尺寸不一致不拉伸、不冒充严格结果，任务暂停且原件在素材库可取，不自动重新生图。该保证针对保存主图的解码像素，不保证选区内结构、光影或接缝质量。
- 带 EXIF 旋转或镜像方向的图片不直接参与严格合成或重新编码，需先另存为方向正常的 PNG；同时检查原始 EXIF 与解码器方向，避免旧版 FFprobe 漏报 PNG 方向。原图/蒙版在付费提交前检查，返回图方向异常则保留原件并暂停。无需转换时继续保存原字节和方向信息，不静默删除方向标记。
- 所选 PNG/JPEG/WebP 格式与渠道实际格式不同时，服务端生成真实编码副本；JPEG/WebP 指定压缩质量时实际重新编码，JPEG 透明区域铺白。已匹配格式且未指定压缩时沿用原件字节。严格蒙版的 JPEG/WebP 仅作为额外导出副本，有损文件不保证区域外逐像素一致。图片下载可选择显示结果、渠道原件或格式副本，关系随服务端资产保存；仅主结果加入任务结果列表。导出副本失败保留严格 PNG 并提示，本地处理失败不自动重发付费请求。服务端需要 FFmpeg/ffprobe，原件不被转换覆盖。
- 点击画布图片会自动带入左侧创建区作为参考图；框选多张图片可统一输入修改提示词，点击缩略图前移/后移或直接拖动调整提交顺序。生成修改图会保留原图，并避开已有节点放置结果。
- 单选画布生成图片时，创建栏自动回填该图已保存的模型、原提示词、尺寸、画质、数量与高级参数，助手栏仍只回填原提示词；参考图仍是当前选中的图片，不替换成历史输入图，也不自动生成。切换到无提示词图片或多选时清空提示词，未保存的生成设置不覆盖当前值；取消选中保留草稿。同一选中图片的拖动或后台刷新不覆盖正在调整的参数。快捷批量生成的新图片保存原始批量数量，历史记录中未保存的批量数无法反推；不可用模型和参数沿用当前模型可用性检查。节点编辑框优先保留显式草稿，没有草稿时显示原提示词。
- 点击空白处或非图片节点取消选中，不清空已带入的编辑参考图；原图再次手动保存后同步更新引用。选择其他图片可替换画布参考图，参考图栏的移除和清空仍显式生效。
- 两套 API 的每个图片任务固定输出一张，不提供单任务张数选择；批量编辑可一次选择 1–100 张本地原图，每张建立独立单图任务，后台控制并发，支持暂停、继续和取消。系列配方一次只执行一条候选；多参考图合成同一结果与多项独立任务是不同用法。
- 旧草稿中的多张数量在新提交时归一为 1，已存在的多结果历史和系列候选保留。成功项进入历史和素材库；默认关闭内部积分时不扣分，正式后端启用计费后按任务价格快照结算。
- 模拟模式仍走真实队列、历史和对象存储，用于不调用模型的业务验收。

## 公司设计灵感库（企业 OA 可选能力）

仅在 `OA_LOGIN_ENABLED=true` 且已通过 OA 员工身份验证时开放；当前免登录试用部署不启用此功能，不使用共用身份模拟公司员工。

- 员工自主发布设计思路、提示词和明确选中的原图，支持公司分享／我的分享、关键词、标签与分页查看。发布保存独立快照，不把原私有素材、整个画布、聊天或隐藏元数据公开；之后修改原素材不改动已发布版本。支持 PNG／JPEG／WebP／GIF，最多 12 张、单张 20 MiB、合计 100 MiB，保留原始字节。
- 素材库和生图结果提供“分享到设计灵感库”，预填所选图片、当时的提示词和标题，来源模型仅供核对；仍需本人勾选分享确认并提交，不自动公开。列表使用 256 像素 WebP 缩略图，读取失败回退原图；下载始终使用原文件。原件与缩略图的 ETag 缓存每次重新鉴权，撤回后不能借 304 继续访问。
- 同事可下载原图、复制提示词，或“放到我的画布”继续创作。加入画布会创建接收人拥有的独立私有素材，保留来源归因与原始比例；后续私人画布和创作不会反向公开，也不会自动调用模型。
- 作者可查看作品浏览次数（PV）与去重人数（UV）、提示词复制次数／人数，以及逐张图片的浏览、下载与画布复用次数／人数。作者自己的操作不计入；同一成功请求不会重复计数，同一员工多次操作可增加次数，但人数仍去重。列表预取不计作品浏览。
- 下载／复用明细按图片显示同事姓名、部门、操作与时间并分页，不提供浏览者名单或同事私人画布内容。下载统计仅表示浏览器交付流程的成功收据，不证明文件已保存到外部磁盘或用于实际设计；画布复用在私有原件及本地画布保存成功后提交收据。统计提交失败会单独提示，不撤销已完成的下载或保存。
- 作者可撤回分享；正式管理员通过独立严格维护入口下架并记录原因，部门管理员仅管理所属部门的分享及统计，不把 OA 设计师提升为管理员。撤回／下架阻止后续共享访问、下载和复用，不能收回已下载或已加入他人画布的副本；单机演示没有真实管理员入口。真实 OA 员工与正式 PostgreSQL／S3 部署仍需目标环境验收。

## 素材、项目与历史

- 服务端素材、任务、批次与历史按游标分页，默认 60 条、最多 200 条；列表仅保留展示摘要，完整提示词、参数和输入归档在打开／复用时获取。素材库、管理任务和历史滚动到底自动继续加载，失败时保留手动重试；公司素材的设计师筛选由服务端执行，不限于已载入的第一页。新结果刷新后位于前面，恢复原任务不受分页截断。
- 素材库支持复选、Shift 连选、`Ctrl/Cmd+A` 选择当前已载入项（最多 50 项），底部可批量删除、ZIP 下载、加入画布或移动项目。一次批量请求先验证全部权限再执行；未获权限的混合选择不会部分删除。演示模式的项目同步和移动结果也写入本机 SQLite。
- 素材库增加标签、日期与时间排序筛选，并提供 30 天回收站；恢复前确认权限、期限和原文件仍存在，重复来源冲突不覆盖现有素材。并行上传逐项报告结果，失败项可单独重试；下载及分享更新不重新加载整页。
- 上传与生成图片异步建立两档 WebP 缩略图，原件保持不变。缺失缩略图由数据库待办持续领取，每个 API 最多 2 项并行、单项最多 4 次尝试；退出归还、重启恢复，失败时仍可读取原图。原文件采用流式响应，先验证当前用户权限再处理 ETag；缓存必须重新鉴权，切换身份不能借 304 绕过访问限制。
- 生图结果卡和历史小图使用显示专用的派生预览；服务器素材读取授权缩略图，本地图片复用员工分区预览缓存。打开大图、编辑与下载继续使用原文件，历史小图进入可视范围后才读取本地图片。
- 画布图片缩略图读取失败时自动尝试原图一次；原图仍失败时显示“图片读取失败”和“重新加载”。手动重试只读取图片，不改变节点或提交生成任务。正式原件与缩略图接口支持单段字节范围读取，客户端断开会终止上游读取；不支持多段拼接响应。

- 网页参考图采集内置于画布右上角，点击进入独立审核页，可返回原画布；素材库也有入口。粘贴公开 HTTP／HTTPS 网页链接即可采集，无需插件，先预览和勾选，确认后才写入当前员工素材库，不占用图片工具栏。原始文件不压缩、不重绘；支持 PNG／JPEG／WebP／GIF，每批最多 20 张，单张 10 MiB、总计 30 MiB；单张失败单独提示，取消采集不会自动入库，来源记录移除查询参数和片段。仅解析公开 HTML，不执行网页脚本，不携带登录凭据，不能访问内网、非标准端口或绕过网站限制；临时采集记录 5 分钟过期，页面草稿刷新或离开即丢失，使用者须确认保存权限。
- 网页扫描最多列出 100 个候选，选择最多 20 张后才读取图片预览，再确认入库；读取与上传分别限制并发。单张失败不阻断其他项，重试跳过已完成项，账号变化立即停止后续写入。
- Chrome 采集扩展仍是可选补充，安装说明默认收起。扩展扫描浏览器当前网页并仅请求画布与所选图片域名权限，再送入同一审核页；不保证能读取登录或防盗链图片，不自动翻页、不采视频。安装说明见审核页及 `tools/chrome-reference-importer/README.md`。
- 普通生图／参考图改图的新记录保存版本化输入归档：原始提示词、模型配置、生成参数与有序参考图的原始文件及校验值。恢复时先检查员工、模型可用性和全部原图，成功后才填回草稿，不自动生成或收费；原图缺失／变更、权限变化或旧记录没有归档时明确提示，不静默替换成当前图片。图片工作台可显式“恢复为草稿继续改”，画布从生成结果的图片菜单新增恢复配置；普通画布不把蒙版或专用工具任务降级为普通改图。创意场景另行保存本地原图与选区副本，不承诺跨设备恢复；缺失文件暂无补传恢复入口。恢复输入不保证再次生成相同画面。
- 上传图片、视频和文本，生成结果自动进入服务端素材库。
- 素材库、个人/共享提示词、图片/视频创作台及管理历史保留当前会话中的输入或筛选状态，退出账号后清空会话草稿；保存、复用和生成操作有重复点击保护与失败提示。
- 服务端素材的标题、标签、来源说明和备注通过带权限检查的接口更新，保留原始文件和生成信息；浏览器本地素材仍保存在本机，不与服务端素材混写。
- 个人与共享提示词按服务端总数分页查询，不再仅展示前 100 条；编辑时保留视频时长、模式等未显示在通用表单中的参数，保存失败保留表单内容。
- PostgreSQL 保存素材归属、项目、任务、提示词、模型和来源；S3/MinIO 保存文件内容。
- 企业模式的服务端素材按已验证员工归属，媒体读取同样校验；试用完整后端按浏览器访客会话归属，Windows 试用共用固定身份，不承诺员工隔离。旧账号素材不自动公开。
- 历史部门和管理员权限仍在服务端维护，普通创作入口不提供公司管理功能。
- 历史记录保存原图、结果、提示词、模型、参数、积分、人民币成本、状态与失败原因。
- 管理员可导出 CSV 用于财务、审计和内部复盘。

## 审计与运维

- Nginx 与单机静态服务压缩文本资源，哈希静态文件长期缓存，入口 HTML 不缓存；上传按允许类型及真实字节检查，下载使用安全文件名和 `nosniff`。聊天流式代理的超时与禁止重放设置保留。
- 正式任务采用带心跳的模型租约和按到期时间调度的延迟队列。视频等待期间不占本地执行槽位，但仍计算模型在途并发；有原任务编号时只恢复查询，提交不确定时暂停核查，不自动重复付费。
- 现有异步服务商工作流同样保存上游任务与协议指纹，重启后查询原任务并沿用原期限；配置变更时暂停核查。API 关闭先停止接收请求、排空在途响应，再关闭后台处理及数据库，不提前切断正在保存的数据。
- APIMart 图片参考直接使用原始字节，避免多次 base64 往返；视频预检在短事务外流式读取并探测，重新进入事务时核对模型与素材快照。媒体结果通过有大小限制的临时文件上传对象存储，成功、失败和中断均清理临时文件。API 运行镜像只安装生产依赖并复制运行源码，不打包测试目录。
- 根目录 `bun run dev` 同时启动本地前后端，`bun run check` 检查 lint、构建和测试。镜像发布依赖验证工作流，并分别构建前端与 API；普通代码推送不执行公司服务器部署。

- 登录、改密、账号变更、额度调整、Provider/工作流配置、导出和任务失败均写入审计。
- 系统集成页只显示企业微信、加密密钥和对象存储是否就绪，不返回 Secret。
- Docker Compose 提供 PostgreSQL、Redis、MinIO、Worker、初始化和定时备份。
- Nginx 为素材库 `/assets` 与 `/assets/` 提供独立页面回退，直接访问或刷新不会落入同名静态目录；实际 `/assets/*` 文件仍按原路径提供。
- GitHub Actions 验证迁移、身份隔离、备份恢复、40 人并发及任务/账本/素材数量一致性。

## 生成操作便捷性

- 图片页保存原请求与生成参数，刷新后继续查询已有任务；停止本页查询不会取消服务端生成，稍后可继续查询，不会重发生成请求。
- 图片、视频状态查询采用有界等待和短暂失败重试，查询暂停不误报生成失败；视频恢复按记录合并，保留其他任务结果。
- 同账号参考图按内容 SHA-256 复用，减少重复上传；配置刷新失败保留已加载模型，后台标签页暂停刷新，模块初次加载失败可直接重试。
- 后台新增结果不明任务核查入口，可关联已有 APIMart 任务继续查询；Worker 暂时断连后退避恢复，延迟任务保持原排队时间，每位员工的在途任务上限可配置。
- 构建通过类型和体积校验后才替换前端产物，失败时保留上一版；共享任务契约及浏览器回归覆盖上传、工作流、撤销刷新、多标签冲突和批量暂停恢复。

模型与参数记忆沿用现有持久化配置；9 张创意场景封面已无损转换为 WebP，合计约由 18.31 MB 降为 11.25 MB（约 38.6%，不宣称达到教程估计的 70%）。原 PNG 可从 Git 历史恢复。

- 图片、视频工作台在原任务提交成功后展示同模型可运行队列名次，区分排队、延迟调度、生成、暂停及完成。预计剩余时间使用最近 7 天、最多 30 条同模型同操作的成功耗时，至少 3 条样本才估算；调度变化、混合操作、超时或样本不足会显示暂无可靠估算，不保证完成时间。本机试用没有共享 Worker 队列，会明确标注。状态查询失败不影响原任务，也不自动重新提交。
- 提示词库及我的提示词卡片提供“发送到生成页”，只填入草稿；“填入并生成”仍是独立的显式操作。“插入到画布”可选择已有私有画布或新建草稿，加入完整可编辑文字节点，保留模板版本、模型、参数和参考资产编号，支持撤销；不复制参考图片、不覆盖已有节点，也不触发模型生成。插入前重新校验模板权限，账号切换或页面关闭会取消尚未完成的操作；保存失败明确提示，避免重复插入。
- `useGenerationWorkspace` 共用参考图状态、参数与历史浮层、历史选择及删除流程；模型规则、图片／视频参考校验和媒体处理仍独立。删除失败保留确认框和选择，进行中拒绝重复删除；图片、视频页按员工重新建立工作区，不沿用另一账号的界面状态。
