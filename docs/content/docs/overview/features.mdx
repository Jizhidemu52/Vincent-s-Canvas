# 功能介绍

画布左侧创建面板在参考图上传、任务提交期间短暂锁定，服务器接收后即可继续提交下一项，无需等待上一项生成完成。每项任务独立保留提交时的提示词、参数和参考图；实际执行并发仍受服务端模型配置限制。

无线画布由设计师创作端、管理员后台和生产业务后端组成。账号、额度、模型、任务、素材、历史和审计使用同一套服务端数据，不依赖前端模拟身份。

## 登录与权限

- 中文账号、英文账号、邮箱或工号加密码登录。
- 新账号首次登录强制修改密码。
- 企业微信扫码登录，并预留 LDAP/OIDC 身份适配接口。
- 超级管理员修改初始密码后可直接进入业务后台。
- 超级管理员管理全公司；部门管理员只管理本部门；设计师只看本人数据。
- 停用账号会使已有 Session 失效，所有管理员 API 都在服务端校验角色。

## 账号与额度

- 管理员创建、停用、重置账号，支持 CSV 批量导入约 100 位设计师。
- 设置部门、角色、初始积分、当前余额和额度上限。
- 操作价格与模型价格相加后在前端显示预估。
- 提交任务先冻结积分，成功捕获，失败、取消或超时释放。
- `requestId` 保证幂等，同一任务不会重复扣费。
- 账本记录调整、冻结、结算、释放及操作人。

## Provider、模型与工作流

- 管理 OpenAI 兼容、Gemini、火山引擎、RunningHub、ComfyUI、自定义及内部 Provider。
- API Key 只在管理员端提交，使用服务端加密密钥保存，设计师接口不返回原文。
- 模型配置包含能力、单次积分、人民币成本、并发限制和启用状态。
- 服务端验证任务类型与模型能力，音频任务不能误用图片模型。
- RunningHub、ComfyUI 和自定义工作流统一配置提交路径、状态路径、模板变量、成功/失败值与结果路径。

## 图片、视频与音频

- 文生图、参考图编辑、局部编辑、细节增强、角度控制和无缝拼接。
- 视频工作台和画布按型号提供首帧、尾帧、首尾帧、多素材参考、编辑或续写，支持对应型号允许的图片/视频/音频输入及有序引用。
- 视频提交前检查素材所有权与模式限制，服务端读取媒体实际尺寸、时长和帧率；无效素材不会直接触发付费生成。音视频参考需要渠道可访问的 HTTPS 素材入口。
- 画布音频节点可提交服务端音频任务并保存结果。
- 图片、视频、音频和工作流任务全部进入 Redis 队列，由 Worker 解密 Provider 凭据后调用上游。
- 设计师浏览器不保存外部模型 API Key，也不直接调用带密钥的上游接口。

## 无限画布与批量改图

- 在线画布助手默认在发送消息时读取当前可见、选中或正在预览的素材，不必逐一附加。优先预览与选中内容，排除画面外、折叠批次和被面板完全遮挡的未选中节点；移动画布后，下一条消息使用新的视口上下文。输入框上方可关闭自动读取，手动参考和画布结构仍保留。
- 自动上下文每轮最多包含 24 个节点、6 张图片、2 个视频及 12000 字符文本；单节点文本最多 3000 字符。图片与视频抽样图最长边 1280 像素，仅供理解，不改动原素材。视频提供开头、中间、结尾的带时间抽样帧，不代表完整动作分析，音轨不自动收听或转写。超限与读取失败在模型上下文中明确标注；自动读取不触发生成或编辑。
- 空白处右键“生成”打开创建面板并记住点击时的画布坐标，下一批图片从该位置向右、向下排列；生成完成后左上角位置不漂移。定位只消费一次，参数校验失败不会丢失定位，可点击“取消定位”恢复原有自动排版。点击菜单本身不提交付费任务。
- 画布快捷键避开输入法选字、表单与弹窗控件；空格临时拖拽在窗口失焦后复位，长按粘贴键不连续复制节点。
- 项目数据和视口未变化时不更新修改时间、不重复触发项目持久化，保留节点与连线数组引用。
- 多项目画布、节点拖拽缩放、连线、撤销重做、导入导出和小地图。
- 图片、文本、视频、音频和生成配置节点可互相连接。
- 图片工具栏的“编辑图片”打开手动编辑面板，支持框选裁剪、画笔、矩形、箭头、文字、马赛克、旋转及面板内撤销/重做。确定后以 PNG 保存回原画布节点，保留连线；取消不改变图片。保存后可用画布撤销恢复原图，再次点击图片可使用独立的“AI 编辑”，手动编辑不会自动调用模型。
- 手动编辑保存到本机浏览器存储，不代表云同步；面板按需加载，保留图片原始分辨率（最长边不超过 8192 像素、总像素不超过 2500 万），超限明确提示。马赛克仅为视觉遮挡，敏感信息应使用不透明涂画完全覆盖。
- 当前编辑会话内绘制的矩形可在矩形工具下直接拖动，支持撤销/重做；按 Shift 可在已有矩形内新建矩形。保存后标注合并为 PNG，不保留跨会话可编辑图层。
- OpenToken 图片尺寸提供自适应选项；比例设置只影响下一次 AI 生成，不直接改变已有图片。自适应由模型结合描述与参考图决定输出尺寸，不保证严格等于原图比例。
- 单张透明图通过 OpenAI 兼容图片编辑入口提交时，自动附带原生 `background=transparent`、`output_format=png`；只读取透明度，不改变输入文件，模型返回文件原样保存。没有额外的背景开关、补底、抠图或透明区域合成；此行为不覆盖多图合成、蒙版编辑及其他渠道。模型仍可能误解修改范围，不保证未指定区域逐像素不变。
- 点击画布图片会自动带入左侧创建区作为参考图；框选多张图片可统一输入修改提示词，点击缩略图前移/后移或直接拖动调整提交顺序。生成修改图会保留原图，并避开已有节点放置结果。
- 点击空白处或非图片节点取消选中，不清空已带入的编辑参考图；原图再次手动保存后同步更新引用。选择其他图片可替换画布参考图，参考图栏的移除和清空仍显式生效。
- 批量一键改图支持选择多张图片、统一提示词、逐张排队和逐张状态。
- 单张失败不影响整批；成功项分别进入历史和素材库并单独结算积分。
- 模拟模式仍走真实队列、账本、历史和对象存储，用于不调用模型的业务验收。

## 素材、项目与历史

- 上传图片、视频和文本，生成结果自动进入服务端素材库。
- 素材库、个人/共享提示词、图片/视频创作台及管理历史保留当前会话中的输入或筛选状态，退出账号后清空会话草稿；保存、复用和生成操作有重复点击保护与失败提示。
- 服务端素材的标题、标签、来源说明和备注通过带权限检查的接口更新，保留原始文件和生成信息；浏览器本地素材仍保存在本机，不与服务端素材混写。
- 个人与共享提示词按服务端总数分页查询，不再仅展示前 100 条；编辑时保留视频时长、模式等未显示在通用表单中的参数，保存失败保留表单内容。
- PostgreSQL 保存素材归属、项目、任务、提示词、模型和来源；S3/MinIO 保存文件内容。
- 设计师 A 无法列表、读取或下载设计师 B 的素材。
- 部门管理员只看本部门，超级管理员可按设计师和部门筛选全公司素材。
- 历史记录保存原图、结果、提示词、模型、参数、积分、人民币成本、状态与失败原因。
- 管理员可导出 CSV 用于财务、审计和内部复盘。

## 审计与运维

- 登录、改密、账号变更、额度调整、Provider/工作流配置、导出和任务失败均写入审计。
- 系统集成页只显示企业微信、加密密钥和对象存储是否就绪，不返回 Secret。
- Docker Compose 提供 PostgreSQL、Redis、MinIO、Worker、初始化和定时备份。
- GitHub Actions 验证迁移、身份隔离、备份恢复、40 人并发及任务/账本/素材数量一致性。

## 仍需公司环境提供

- 正式域名、HTTPS 网关和 Linux 私有云服务器。
- 企业微信自建应用参数与可信回调域。
- 正式数据库、Redis、对象存储和 Provider 凭据。
- 各真实模型供应商的限流、超时和成本验收。
