在新建的合成 QA 画布操作真实界面，没有 mock，也没有使用员工私有项目。完整任务、输入、最终提示词与原始图片哈希见同名 JSON。

## 两步工作流

从奶油色 V 领无袖针织背心创建“白底保形 → 海军蓝换色”，点击一次运行。实际捕获 2 次图片任务 POST；每步各在服务端内联编译，两个任务均成功且 optimized=true。

- 第一步任务：`03fc4efc-4983-4266-a706-03af885b2027`，白底、V 领、无纽扣、无口袋保留；针织纹理有细微重绘。概念图 PASS，不宣称像素不变。
- 第二步任务：`b0813d46-110a-4bbf-8d43-06302d775d61`，服装及领口、袖口、下摆罗纹均改海军蓝，白底和款式结构保留。概念图 PASS，不代替实物色差验收。
- 第二步引用经重新上传获得新素材 ID，但下载字节 SHA-256 与第一步结果相同：`e53311787e3037043fb3e24549774e53db7845625dd74761d9d64b0ef3f5ef2d`；任务 inputArchive 的参考图哈希也相同。用字节证明传递关系，不以素材 ID 不同误判。
- 刷新后两个“本步已完成”和 2/2 状态、两张结果均恢复。未观察到新增付费 POST，但开发环境重载超出浏览器事件缓冲范围，因此此处不将网络截面描述为完整的无重复提交证明。

4 个 PNG 分别为源图、第一步结果、第二步结果、第二步实际输入。最后一个是第一步结果的同字节复本，不是第三次生图。真实供应商费用未知。

## 模板连线

另一张新画布通过菜单依次添加“整套款式开发”“花型与工艺开发”“系列配色提案”。返回画布列表后，持久化统计为 12 个节点、9 条连线，即 3 个参考图占位和 9 个配置节点。没有点击开始生成，添加模板没有图片调用。

前两组的三条可见引用分别指向本组同一参考图；第三组创建与总数已核验。远景虚拟化时 DOM 不包含全部节点，连线由 canvas 绘制而非 SVG，故不声称用 DOM 实测了全部边。精确的三个并列分支关系另由模板构造单元测试覆盖，九节点实图验证保留在主矩阵中。

另一位执行者准备的蓝衬衫画布没有运行，handoff-report.json 的 0 POST 如实保留；含浏览器私有状态的交接文件不公开。
