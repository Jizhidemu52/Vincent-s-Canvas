# 无线画布：本地与局域网部署说明

这份说明适用于把项目放在一台 Windows 电脑上运行，并让同一局域网内的同事通过浏览器使用。运行这台电脑会代为调用已配置的模型额度；拿到网页链接的人不需要单独配置模型 Key。

> 不要把 API Key 发到群里、写进 GitHub，或粘贴到前端配置。Key 只保存在运行电脑的 `server/.env`。

## 1. 准备条件

- Windows 10 或 Windows 11
- 已安装 [Bun](https://bun.sh/)，在 PowerShell 运行 `bun --version` 能显示版本号
- 已从 GitHub 下载或克隆本项目
- 运行电脑可以访问模型服务商网络

## 2. 第一次安装

在项目根目录打开 PowerShell，依次执行：

```powershell
cd web
bun install
bun run build

cd ..\server
bun install
```

完成后，浏览器页面所需的生产文件会生成在 `web/dist`。

## 3. 配置 OpenToken（只在运行电脑做一次）

1. 进入 `server` 文件夹。
2. 若没有 `server/.env`，复制 `server/.env.example` 并重命名为 `.env`。
3. 在 `server/.env` 最后加入以下两行，再填入自己的真实 Key：

```ini
OPENTOKEN_BASE_URL=https://cn2.gw.opentoken.io/v1
OPENTOKEN_API_KEY=在这里填入真实 OpenToken Key
```

4. 保存文件。不要把这个 `.env` 文件上传、压缩发送或提交到 Git。

配置成功后，图片模型列表会显示已启用的 `open gpt2` 与 `gemini`；没有配置 Key 的模型不会显示。

## 4. 启动并在本机使用

双击项目根目录的 `Start-LAN.bat`。

首次启动时，如果 Windows 询问防火墙权限，请允许专用/公用网络访问。若脚本提示不能创建防火墙规则，请右键 `Start-LAN.bat`，选择“以管理员身份运行”一次；之后可以正常双击启动。

脚本会显示类似下面的地址：

```text
LAN trial is ready: http://192.168.1.115:5188/
```

先在运行电脑的浏览器打开该地址，确认能进入画布并完成一张测试图片生成。

## 5. 让同一局域网的同事使用

把脚本显示的完整地址发给同事，例如：

```text
http://192.168.1.115:5188/
```

使用者必须满足以下条件：

- 与运行电脑连接到同一个公司/家庭局域网；
- 使用脚本实际显示的地址，不要使用旧地址或 `127.0.0.1`；
- 运行电脑保持开机，且服务没有停止。

同事在浏览器中打开地址后即可使用。单机版不需要登录，也不显示积分扣费；模型调用仍消耗运行电脑所配置 Key 的服务商额度。

## 6. 更新到 GitHub 最新版本

在项目根目录执行：

```powershell
git pull origin main

cd web
bun install
bun run build

cd ..\server
bun install
```

然后重新双击 `Start-LAN.bat`。更新不会替换 `server/.env`，但更新前建议自行备份该文件。

## 常见问题

### 其他电脑打不开网页

确认两台电脑在同一局域网；使用启动窗口打印的地址；检查运行电脑没有休眠；必要时以管理员身份重新运行 `Start-LAN.bat` 以创建防火墙规则。

### 网页能打开，但生成图片失败

检查 `server/.env` 是否存在 `OPENTOKEN_API_KEY`，Key 是否有效、是否有额度；保存后重新启动 `Start-LAN.bat`。模型下拉框只会显示已经配置成功的服务。

### 其他同事能打开但等待很久

图片/视频耗时主要由上游模型生成决定。先在运行电脑本机生成一张同样规格的测试图：若本机也慢，属于模型服务耗时或额度/排队问题；若本机快而其他电脑慢，检查运行电脑网络、Wi-Fi 信号和局域网稳定性。

### 需要让外网人员长期访问

局域网地址只能在同一网络内使用。长期对外开放建议部署到有公网 IP 的服务器并配置域名与 HTTPS，或由公司 IT 提供安全的内网穿透/反向代理。不要直接把运行电脑暴露到公网，也不要把 API Key 发给外部用户。

## 安全提醒

- 所有使用者共享运行电脑配置的模型额度。
- 不要上传涉及客户机密、个人隐私或未经授权的图片资料。
- 演示服务重启后，临时会话和本地演示数据可能会重置；重要成果请及时下载或保存。
