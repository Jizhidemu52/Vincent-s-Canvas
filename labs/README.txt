独立设计实验室

此目录保存可独立试用的设计 Demo 与模块验证，不改变正式 web/server 入口、接口、数据库或部署。
正式应用与 Docker 镜像不会加载此目录。不得把实验页的通过结果当成正式企业部署验收。

先试这里：design-workbench/
中文的图案定位、花型循环和系列配方。
图案定位与循环可实际编辑、保存和导出；系列配方为本地模拟，不调用人工智能。
系列配色支持逐色选择、HEX 输入，以及柔和、鲜明、大地、自由四种随机风格。
Windows 启动入口为 design-workbench/Start-Demo.cmd；详细方式、测试命令和边界见该目录 README.txt。

模块验证：source-modules/
固定六个上游仓库的源码版本，真实执行相关模块，仅外部模型／数据库等边界用明确标记的夹具替代。
保留原始能力缺口：Fabric 文档锁定持久化和清空路径、tldraw 示例执行器的取消／并发写回／缓存等。
源码准备、依赖和运行步骤见该目录 README.txt；上游仓库按固定提交下载，不把整仓和 node_modules 提交到本仓库。

当前边界
1. 业务演示与模块测试独立运行，验证结论分别记录。
2. 本机监听、无付费模型调用；演示图片不代表人工智能效果、潘通标准或生产色卡。
3. 潘通色库按当前要求暂不接入。不能把 HEX 或随机颜色称作已匹配潘通色。
4. 第三方源码与依赖保留各自许可证；实验记录不构成商业许可意见。
5. 本地完整历史证据、失败依赖备份和大型图片产物不上传；仓库保留必要验证摘要与可重跑脚本。
6. 上传源码不等于已接入正式画布；后续接入需单独确定范围并修复相关已知缺口。
